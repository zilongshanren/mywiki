This is an improved but unofficial API Reference for Cocos2D (for iOS) hosted on the [Learn & Master Cocos2D website](http://www.learn-cocos2d.com/).

[CCDirectorIOS](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_c_c_director_i_o_s/), [CCDirectorMac](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_c_c_director_mac/), [CCArray](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_c_c_array/), [CCLayer](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_c_c_layer/), [EAGLView](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_e_a_g_l_view/), [CCKeyboardEventDelegate](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/protocol_c_c_keyboard_event_delegate-p/) & [CCMouseEventDelegate](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/protocol_c_c_mouse_event_delegate-p/), [CCProfiler](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_c_c_profiler/), [CCScheduler](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_c_c_scheduler/), probably others too ...

Some of these classes are well documented but just not included in the official docs. Few classes like [CCProfiler](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/interface_c_c_profiler/) are entirely undocumented but at least you see the methods these classes expose, and that the class exists.

There's also a new Modules Tab to make some documented C code more accessible, like CGPointExtension and CCDrawingPrimitives.

The programming guide is hosted here: [http://www.cocos2d-iphone.org/wiki/doku.php/prog_guide:index](http://www.cocos2d-iphone.org/wiki/doku.php/prog_guide:index)
