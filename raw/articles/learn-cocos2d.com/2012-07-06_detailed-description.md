Fades In an object that implements the [CCRGBAProtocol](http://www.learn-cocos2d.com/api-ref/1.1/cocos2d-iphone/html/protocol_c_c_r_g_b_a_protocol-p/) protocol. It modifies the opacity from 0 to 255. The "reverse" of this action is FadeOut
