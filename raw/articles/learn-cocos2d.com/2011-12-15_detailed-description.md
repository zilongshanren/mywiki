`#include <CCActionInterval.h>`


Fades Out an object that implements the [CCRGBAProtocol](http://www.learn-cocos2d.com/api-ref/1.0/cocos2d-iphone-mac/html/protocol_c_c_r_g_b_a_protocol-p/) protocol. It modifies the opacity from 255 to 0. The "reverse" of this action is FadeIn
