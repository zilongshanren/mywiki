Particle System base class Attributes of a Particle System:

cocos2d also supports particles generated by Particle Designer ([http://particledesigner.71squared.com/](http://particledesigner.71squared.com/)). 'Radius Mode' in Particle Designer uses a fixed emit rate of 30 hz. Since that can't be guarateed in cocos2d, cocos2d uses a another approach, but the results are almost identical.

cocos2d supports all the variables used by Particle Designer plus a bit more:

It is possible to customize any of the above mentioned properties in runtime. Example:

emitter.radialAccel = 15; emitter.startSpin = 0;
