For the second edition of the [Learn Cocos2D book](http://www.apress.com/book/view/9781430233039) I compiled an alphabetically sorted list of tools that developers can use for cocos2d projects. Please let me know if there’s a tool missing from this list or if there’s one that won’t work anymore and hasn’t been updated in months.

The following tools can be used for development with cocos2d:

#### Bitmap Font Tools

[BMFont](http://www.learn-cocos2d.com/www.angelcode.com/products/bmfont/) (Windows)

[Fonteditor](http://www.learn-cocos2d.com/code.google.com/p/fonteditor/)

[Glyph Designer](http://www.learn-cocos2d.com/glyphdesigner.71squared/)

[bmGlyph](http://www.bmglyph.com/)

[Hiero](http://www.learn-cocos2d.com/slick.cokeandcode.com/demos/hiero/)

[LabelAtlasCreator](http://www.learn-cocos2d.com/www.cocos2d-iphone.org/forum/topic/4357/)

#### Particle Editing Tools

[ParticleCreator](http://www.cocos2d-iphone.org/forum/topic/16363)

[Particle Designer](http://particledesigner.71squared.com/)

#### Physics Editing Tools

[Mekanimo](http://www.mekanimo.net/)

[PhysicsBench](http://www.cocos2d-iphone.org/forum/topic/9064)

[PhysicsEditor](http://www.physicseditor.de/)

[VertexHelper](http://www.cocos2d-iphone.org/archives/779)

#### Scene Editing Tools

[CocosBuilder](http://cocosbuilder.com/)

[Cocoshop](http://www.cocos2d-iphone.org/forum/topic/15668)

[LevelHelper](http://www.levelhelper.org/)

#### Texture Atlas Tools

[DarkFunction Editor](http://darkfunction.com/)

[SpriteHelper](http://www.spritehelper.org/)

[TexturePacker](http://www.texturepacker.com/)

[Zwoptex](http://zwoptexapp.com/)

#### Tilemap Editing Tools

[iTileMaps](http://www.klemix.com/page/iTileMaps.aspx)

[Tiled Map Editor](http://www.mapeditor.org/)
