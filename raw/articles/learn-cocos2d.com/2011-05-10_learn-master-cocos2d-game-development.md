# Docs

I’m hosting API References for important technologies surrounding Cocos2D which are either incomplete (Cocos2D API Reference) or inaccessible on the web (Box2D API Reference is not available online).

The links above this page will take you to the respective API References that I’m hosting on this site as a service for my readers, and myself. Currently this includes the [Unofficial Cocos2D API Reference](http://www.learn-cocos2d.com/unofficial-cocos2d-api-reference/html/index/) and the [Box2D API Reference](http://www.learn-cocos2d.com/box2d-api-reference/API/index/).

Other API References are available online, typically hosted by the developers but not always straightforward to find. These API References should be of interest to you:

[Chipmunk Documentation](http://files.slembcke.net/chipmunk/release/ChipmunkLatest-Docs/)

[Objective-Chipmunk API Reference](http://files.slembcke.net/chipmunk/release/Objective-ChipmunkLatest-Docs/) ([What is Objective-Chipmunk?](http://howlingmoonsoftware.com/objectiveChipmunk.php))

[ObjectAL for iPhone Documentation and API Reference](https://kstenerud.github.com/ObjectAL-for-iPhone/documentation/index.html)

[CocosDenshion FAQ](http://www.cocos2d-iphone.org/wiki/doku.php/cocosdenshion:faq) and [CocosDenshion CookBook](http://www.cocos2d-iphone.org/wiki/doku.php/cocosdenshion:cookbook)

[Wax Wiki](https://github.com/probablycorey/wax/wiki) and the [Lua Reference Manual](http://www.lua.org/manual/5.1/) plus the [Programming in Lua 5.0 Online Book](http://www.lua.org/pil/).
