The game I worked on called [YETIPEE is now available worldwide in the App Store](https://itunes.apple.com/app/yetipee/id555343706?l=en&mt=8). YETIPEE is the english version of YETIPIPI.

Previously it was only available to german users. Now you have no more excuses - get the game! ![:)](../../../wordpress/wp-includes/images/smilies/simple-smile.png)


If you’re interested to learn more about the technical details of this game, check out the [YETIPIPI postmortem](http://www.learn-cocos2d.com/2012/12/game-wrote-finally-yetipipi/).
