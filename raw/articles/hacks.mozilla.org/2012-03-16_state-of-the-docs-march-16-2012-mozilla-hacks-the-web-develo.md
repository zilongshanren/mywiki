Documentation activity on MDN continues apace, with lots of work in the French localization, and a focus on CSS docs.

## Web standards docs

**Vikash Agrawal**added a code example to[HTML <figure>](https://developer.mozilla.org/en/HTML/Element/figure).**David Baron**clarified the standardization status of several CSS properties, such as[-moz-background-inline-policy](https://developer.mozilla.org/en/CSS/-moz-background-inline-policy),[-moz-user-focus](https://developer.mozilla.org/en/CSS/-moz-user-focus), and[user-select](https://developer.mozilla.org/en/CSS/user-select).**Fred Bourgeon**translated[:first](https://developer.mozilla.org/en/CSS/%3Afirst)and[:disabled](https://developer.mozilla.org/En/CSS/%3Adisabled)into French.**Julia Buchner**translated the[SVG tutorial section on clipping and masking](https://developer.mozilla.org/en/SVG/Tutorial/Clipping_and_masking)into[French](https://developer.mozilla.org/fr/SVG/Tutoriel/D%C3%A9coupages_et_masquages).**itpastorn**expanded the[Introduction to HTML](https://developer.mozilla.org/en/HTML/Introduction), and**Jim Lancaster**copy-edited it.**Benoit Jacob**added some tips to[WebGL best practices](https://developer.mozilla.org/en/WebGL/WebGL_best_practices).**Scott Johnson**clarified the two types of mobile rendering in[CSS text-size-adjust](https://developer.mozilla.org/en/CSS/text-size-adjust).**Matt Noorenberghe**updated[HTMLMediaElement](https://developer.mozilla.org/en/DOM/HTMLMediaElement).**Robert Nyman**wrote an article on[Using the Camera API](https://developer.mozilla.org/en/DOM/Using_the_Camera_API).**Jeremie Patonnier**documented SVG attributes[accent-height](https://developer.mozilla.org/en/SVG/Attribute/accent-height),[ascent](https://developer.mozilla.org/en/SVG/Attribute/ascent),[result](https://developer.mozilla.org/en/SVG/Attribute/result),[patternTransform](https://developer.mozilla.org/en/SVG/Attribute/patternTransform).**Jean-Yves Perrier**continued working on the CSS reference, adding[text-size-adjust](https://developer.mozilla.org/en/CSS/text-size-adjust); and created articles on[CSS Syntax](https://developer.mozilla.org/en/CSS/Syntax)and[At-rules](https://developer.mozilla.org/en/CSS/At-rule). He also made[Writing efficient CSS](https://developer.mozilla.org/en/CSS/Writing_Efficient_CSS)browser-agnostic and created a best-practices document on[Browser detection using the user agent](https://developer.mozilla.org/en/Browser_detection_using_the_user_agent).**pyalot**created[Using extensions](https://developer.mozilla.org/en/WebGL/Using_Extensions)to explain WebGL extensions.**quantumstate**corrected edge cases in the JavaScript[atan2](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/Math/atan2)article.**Theirry Regagnon**did a lot of clean-up of[Understanding CSS z-index](https://developer.mozilla.org/en/CSS/Understanding_z-index)and added browser compatibility info to[z-index](https://developer.mozilla.org/en/CSS/z-index).**Girish Sharma**added an example about separating Unicode characters to the[JavaScript RegExp](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/RegExp)article.

## Mozilla technology docs

**Mark Giffin**expanded[In-app payments](https://developer.mozilla.org/en/Apps/In-app_payments).**Austin King**wrote up some[developer tips for BrowserID primary identity providers](https://developer.mozilla.org/en/BrowserID/Primary/Developer_tips).**Dave Mandelin**expanded[SpiderMonkey internals](https://developer.mozilla.org/En/SpiderMonkey/Internals).**Jean-Bernard Marcon**and**Benoit Leseul**started translating the[Open Web Apps](https://developer.mozilla.org/en/Apps)pages into French.**Neil Rashbrook**created XUL attribute pages for[textbox.onfocus](https://developer.mozilla.org/en/XUL/Attribute/textbox.onfocus)and[textbox.onblur](https://developer.mozilla.org/en/XUL/Attribute/textbox.onblur).

## Mozilla project docs

**Jeff Beatty**added several sections to the[Localization Quick Start Guide](https://developer.mozilla.org/en/Localization_Quick_Start_Guide).**decoder**updated[Building Firefox with address sanitizer](https://developer.mozilla.org/en/Building_Firefox_with_Address_Sanitizer).**Anthony Hughes**added a section on Litmus to the[Mozmill tests commit policy](https://developer.mozilla.org/en/Mozmill_Tests/Commit_Policy).**Josh Matthews**wrote[Creating a patch that can be checked in](https://developer.mozilla.org/en/Creating_a_patch_that_can_be_checked_in).**Fred Wang**reorganized the[Mozilla MathML project](https://developer.mozilla.org/en/Mozilla_MathML_Project)pages to move out older status information.
