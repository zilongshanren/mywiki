A few days ago I was asked to deliver the first talk of the amazing [Beyond Tellerand](http://2011.beyondtellerrand.com/) conference in Dusseldorf, Germany. The talk [Breaking the barriers – moving browsers and the web forward](http://icant.co.uk/talks/btconf/) introduced a lot of new ideas and technologies that are worked on my Mozilla and others to make the web of the future better.

Here is the video of the presentation with jump points and links to more information. If you want to see the slides of the talk, they are [available here](http://icant.co.uk/talks/btconf/) and there is also [an audio recording on archive.org](http://www.archive.org/details/BreakingTheBarriers-MovingBrowsersAndTheWebForward_679).

[Breaking the barriers – moving browsers and the web forward](http://vimeo.com/33014244) from [marc thiele](http://vimeo.com/marcthiele) on [Vimeo](http://vimeo.com).

Here’s what is covered in the talk:

- Modern web technologies of HTML5 and friends that can be used right now (with
[64 myself](http://c64.superdefault.com/)as a demo) [03:50 – 07:19]- Rich HTML semantics
*(HTML5)* - Self-validating forms
*(HTML5)* - Richer form controls with fallbacks
*(HTML5)* - Canvas for painting in the browser
*(HTML5)* - CSS gradients, multiple backgrounds, animation and transition
- CSS 3D transforms
- Local storage and offline storage
- SVG for scalable and interactive graphics
- RequestAnimationFrame for secure animation
- History API
- WebGL

- Rich HTML semantics
- Taking on challenges – we need you to show the world that web technology is good enough to do jobs that in the past were only possible with native or server-side code (with
[Joe Lambert’s image unshredder](http://www.joelambert.co.uk/unshred/)as the example) [07:20 – 08:04] - Breaking the browser mould – showing that the browser interfaces can be manipulated with HTML and JS (with browser menus,
[context menus](http://www.whatwg.org/specs/web-apps/current-work/multipage/#context-menus)and the[Fullscreen API](https://wiki.mozilla.org/Gecko:FullScreenAPI)as examples) [08:05 – 10:54] - Developing with the web – developer tools in browsers and done in client side technologies (with
[Hackasaurus](http://hackasaurus.org/en-US/goggles/),[Cloud 9 IDE](http://c9.io/), Firefox Scratchpad, Firefox Style Editor,[Parse error display in view-source](http://hsivonen.iki.fi/view-source/)and[Tilt](https://addons.mozilla.org/en-US/firefox/addon/tilt/)as examples) [10:55 – 17:24] - Online identity and issues with current login systems (with
[BrowserID](http://browserid.org/)as a solution to a lot of the problems we have right now) [17:25 – 29:35] - Apps, the shortcomings and myths of native apps and the opportunity to build hybrid apps with web technologies (with
[Open Web Apps](http://mozillalabs.com/blog/2011/07/web-apps-update-experiments-in-web-activities-app-discovery/)and[Web Intents](http://webintents.org/)as examples) [29:36 – 37:34] - Moving web technologies into the mobile space (with
[Are we mobile yet?](http://arewemobileyet.com/)and[Boot to Gecko](https://wiki.mozilla.org/B2G)as demos) [37:35 – 40:11] - How can you help? [40:12 – 42:33]
