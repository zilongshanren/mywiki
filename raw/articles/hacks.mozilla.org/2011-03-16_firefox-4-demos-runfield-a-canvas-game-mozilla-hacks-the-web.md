Yeah! Another awesome demo in [Web’o Wonder](https://demos.mozilla.org/en-US/#runfield)!

With Hardware Acceleration and a fast JavaScript engine, the web platform is ready for Games. Runfield is an example. This HTML5 Game has been developed by [Ilmari Heikkinen](http://twitter.com/#!/ilmarihei). It’s based on Canvas 2D, and this game works on all the recent browsers.
