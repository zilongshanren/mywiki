It has been four weeks since the last State of the Docs update, so there is much to report. As ever, this is just a selection of the recent documentation activity on MDN.

## Web standards docs

**Frédéric Bourgeon**has done a lot of work on pages for CSS selectors, in both English and French including: adding a spec table to[Adjacent sibling selectors](https://developer.mozilla.org/en/CSS/Adjacent_sibling_selectors), and compatibility info in[class selectors](https://developer.mozilla.org/En/CSS/Class_selectors),[type selectors](https://developer.mozilla.org/en/CSS/Type_selectors),[ID selectors](https://developer.mozilla.org/En/CSS/ID_selectors),[universal selectors](https://developer.mozilla.org/en/CSS/Universal_selectors), and[descendant selectors](https://developer.mozilla.org/en/CSS/Descendant_selectors).**David Bruant**started documenting[rest parameters in JavaScript](https://developer.mozilla.org/en/JavaScript/Reference/rest_parameters).**CutenessOverload**updated IE compatibility info for a bunch of CSS properties, including[transform](https://developer.mozilla.org/en/CSS/transform),[font-feature-settings](https://developer.mozilla.org/en/CSS/font-feature-settings),[animation](https://developer.mozilla.org/en/CSS/animation),[transition](https://developer.mozilla.org/en/CSS/transition),[perspective](https://developer.mozilla.org/en/CSS/perspective),[radial-gradient](https://developer.mozilla.org/en/CSS/radial-gradient), and[linear-gradient](https://developer.mozilla.org/en/CSS/linear-gradient).**Dhar**updated the compatibility table for[console.log](https://developer.mozilla.org/en/DOM/console.log).**Fusionchess**added code examples to[:hover](https://developer.mozilla.org/En/CSS/%3Ahover),[:target](https://developer.mozilla.org/En/CSS/%3Atarget), and[:checked](https://developer.mozilla.org/En/CSS/%3Achecked).**RobG**updated[Using the W3C DOM](https://developer.mozilla.org/en/Using_Web_Standards_in_your_Web_Pages/Using_the_W3C_DOM).**Havvy**added a section comparing objects and maps to[Map global objects](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/Map).**Jürgen Jaka**updated[CSS white space](https://developer.mozilla.org/en/CSS/white-space).**michelesalvador**added a code example of interrupting a function to the[JavaScript return statement](https://developer.mozilla.org/en/JavaScript/Reference/Statements/return).**Mokoto Kato**documented[word-break](https://developer.mozilla.org/en/CSS/word-break)and updated a compatibility info for[<ol>](https://developer.mozilla.org/en/HTML/Element/ol), and added compatibility table and info to[CSS transition-property](https://developer.mozilla.org/en/CSS/transition-property).**Masayuki Nakano**documented the behavior in Gecko 15 for[KeyboardEvent](https://developer.mozilla.org/en/DOM/KeyboardEvent).**Jérémie Patonnier**documented SVG attributes[font-variant](https://developer.mozilla.org/en/SVG/Attribute/font-variant),[font-weight](https://developer.mozilla.org/en/SVG/Attribute/font-weight),[image-rendering](https://developer.mozilla.org/en/SVG/Attribute/image-rendering),[writing-mode](https://developer.mozilla.org/en/SVG/Attribute/writing-mode), and[direction](https://developer.mozilla.org/en/SVG/Attribute/direction). He reports that all these SVG attributes are finally starting to drive him crazy :-)**Thierry Régagnon**added a compatibility table and info for[CSS widows](https://developer.mozilla.org/en/CSS/widows).**Rodney Rehm**added a code example for sorting maps to[Array sort](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/Array/sort).**Scott Rowe**updated[CSS flexible boxes](https://developer.mozilla.org/en/CSS/Flexible_Boxes)based on current standards status, and expanded[CSS filter](https://developer.mozilla.org/en/CSS/filter).**Florian Scholz**added ‘markMessageRead’ and ‘read’ to[SmsFilter](https://developer.mozilla.org/en/DOM/SmsFilter)and ‘read’ to[SmsMessage](https://developer.mozilla.org/en/DOM/SmsMessage).**Rob W**updated compatibility info for[Input.setSelectionRange](https://developer.mozilla.org/en/DOM/Input.setSelectionRange).

The Asian language localization communities have been especially busy:

**Ethertank**added or updated Japanese translations for lots of HTML, CSS, and JavaScript pages.**Masahiko Imanaka**created Japanese pages for lots of HTML elements.**Potappo**translated[HTML content categories](https://developer.mozilla.org/ja/HTML/Content_categories)into Japanese.**Yyss**created or updated Japanese translations for the SVG tutorial, and translated a number of HTML, JavaScript, and Firefox-related pages into Japanese.**Ziyunfei**created or updated Chinese translations for lots of DOM and JavaScript pages, including[window.requestAnimationFrame](https://developer.mozilla.org/en/DOM/window.requestAnimationFrame),[Array join](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/Array/join), and[<progress>](https://developer.mozilla.org/en/HTML/Element/progress).

## Mozilla technology docs

**Archaopteryx**added a section on checking if a message is a feed item to the[open folder Thunderbird use case](https://developer.mozilla.org/en/Extensions/Thunderbird/HowTos/Common_Thunderbird_Use_Cases/Open_Folder).**David Bruant**provided browser compatibility details on[Browser ID](https://developer.mozilla.org/en/BrowserID/Quick_Setup).**Matt Brubeck**updated the[Gecko user agent string reference](https://developer.mozilla.org/en/Gecko_user_agent_string_reference).**Marshall Culpepper**created a page for[Setting up Boot to Gecko build environment for Mac OS X](https://developer.mozilla.org/en/Mozilla/Boot_to_Gecko/Setting_up_Boot_to_Gecko_Build_Environment_for_Mac_OS_X).**Mark Finkle**created[mobile code snippets](https://developer.mozilla.org/en/Code_snippets/Mobile)and[Mobile add-ons developer guide](https://hacks.mozilla.org/created https:/developer.mozilla.org/en/Extensions/Mobile/Addons_developer_guide).**Mark Giffin**improved[Validating a receipt](https://developer.mozilla.org/en/Apps/Validating_a_receipt)for HTML5 apps.**Bill McCloskey**documented[SpiderMonkey garbage collector integration](https://developer.mozilla.org/en/SpiderMonkey/Garbage_collector_integration).**Florian Scholz**added ‘notifyMarkMessageRead’ and ‘notifyMarkMessageReadFailed’ to[nsISmsRequestManager](https://developer.mozilla.org/en/XPCOM_Interface_Reference/nsISmsRequestManager).**David Rajchenbach-Teller**added properties and made other updates to[ctypes](https://developer.mozilla.org/en/Mozilla/js-ctypes/js-ctypes_reference/ctypes).**Eric Shepherd**added a bunch of docs for Boot-to-Gecko, which are linked under[Building and installing Boot to Gecko](https://developer.mozilla.org/en/Mozilla/Boot_to_Gecko/Building_and_installing_Boot_to_Gecko). He also added a description of the JSPropertyDescriptor structure to[JS_GetPropertyDescriptorById](https://developer.mozilla.org/en/SpiderMonkey/JSAPI_Reference/JS_GetPropertyDescriptorById).**Jennifer Zickerman**added a section on using LDAP to[Thunderbird enterprise tips](https://developer.mozilla.org/en/Thunderbird/Thunderbird_Enterprise_Tips).

## Mozilla project docs

**Vladan Djeric**documented[Profiling with the built-in profiler and local symbols on Windows](https://developer.mozilla.org/en/Performance/Profiling_with_the_Built-in_Profiler_and_Local_Symbols_on_Windows).**Benoit Girard**documented[Reporting a performance problem](https://developer.mozilla.org/en/Performance/Reporting_a_Performance_Problem).**Jonathan Watt**updated and expanded[Eclipse CDT](https://developer.mozilla.org/en/Eclipse_CDT).
