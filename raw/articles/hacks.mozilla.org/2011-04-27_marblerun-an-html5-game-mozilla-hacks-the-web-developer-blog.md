Take the [HTML5 Canvas element](https://developer.mozilla.org/en/Canvas_tutorial), a Javascript library to do the physics ([box2d](https://github.com/jwagner/box2d2-js)), add a nice design, a social touch, and you have an awesome HTML5 Game called [MarbleRun](https://demos.mozilla.org/en-US/#marblerun)!

MarbleRun was the winner of the last [Mozilla Game On Challenge](http://mozillalabs.com/gaming/2011/02/03/game-on-winners/), among other exciting HTML5 games ([check them out](http://mozillalabs.com/gaming/2011/02/03/game-on-winners/)), and had been added to [Web O’ Wonder](http://webowonder.org).
