**Javascript**- Release of
[Jägermonkey](http://www.bailopan.net/blog/?p=768), Firefox new Javascript engine - Release of
[Kraken](http://blog.mozilla.com/rob-sayre/2010/09/14/release-the-kraken/), a new browser benchmark - SpiderMonkey JSON change:
