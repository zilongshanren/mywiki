By rights, today’s edition of “State of the Docs” should be a little light, since it has been only a week and a half since [a very productive documentation sprint](http://hacks.mozilla.org/2012/04/doc-sprint-in-insert-california-cliche/). But our amazing documentation contributors collectively do not rest, and so there is still lots to mention.

Outside the usual categories of docs, **Tom Lowenthal** created a page of [privacy policy guidelines](https://developer.mozilla.org/en/Privacy_policies), with help from **Jishnu Menon**, along with a [privacy policy template](https://github.com/flamsmark/privacy-policy-template) that you can fork on Github. If you missed the earlier [Hacks post about privacy guidelines](http://hacks.mozilla.org/2012/05/privacy-policy-guidelines-and-template-for-web-apps/), check it out.

## Help needed

**Fbender** added a note to the Talk page for JavaScript [Functions and function scope](https://developer.mozilla.org/en/JavaScript/Reference/Functions_and_function_scope) that “conditionally defining a function throws an error in at least ES5 strict, possibly non-strict (at least soon), too, see [Bug 609832](https://bugzilla.mozilla.org/show_bug.cgi?id=609832) and [Bug 585536](https://bugzilla.mozilla.org/show_bug.cgi?id=585536). The section [Conditionally defining a function](https://developer.mozilla.org/en/JavaScript/Reference/Functions_and_function_scope#Conditionally_defining_a_function) should be updated to reflect those changes.” Want to make that change? Go for it!
