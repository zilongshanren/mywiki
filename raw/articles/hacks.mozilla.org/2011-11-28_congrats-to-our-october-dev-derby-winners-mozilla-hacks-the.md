Responsive design is more important than ever as people experience the Web on a variety of devices. Web developers can now take advantage of [CSS Media Queries](https://developer.mozilla.org/en/CSS/media_queries) to build sites and applications that can be viewed on different screen sizes. So we decided to focus on that for the [October Dev Derby](https://developer.mozilla.org/en-US/demos/devderby/2011/october/).

![Mozilla Demo Studio presents Dev Derby on MDN](../../assets/8edf1f06addeed39.png)


For this challenge, developers submitted [15 demos](https://developer.mozilla.org/en-US/demos/devderby/2011/october/) to show what you can do with CSS Media Queries. Check them out so see how they present unique styles and layouts in response to changes in viewing area.

It was a fairly close race, so join us in congratulating the winners circle:

![October Dev Derby winners - CSS Media Queries October Dev Derby winners - CSS Media Queries](https://hacks.mozilla.org/wp-content/uploads/2011/11/octderbywinners-500x204.png)


**1st Place:** [CSS3 Cherry Blossom – Media queries](https://developer.mozilla.org/en-US/demos/detail/css3-cherry-blossom-media-queries) by [elufo](https://developer.mozilla.org/en-US/profiles/elufo/)

**2nd Place:** [Santa’s Media Queries](https://developer.mozilla.org/en-US/demos/detail/santas-media-queries) by [tuxie](https://developer.mozilla.org/en-US/profiles/tuxie/)

**3rd Place:** [Too many fish is the sea](https://developer.mozilla.org/en-US/demos/detail/too-many-fish-is-the-sea) by [michal.b](https://developer.mozilla.org/en-US/profiles/michal.b/)

**Runners-up:**

[Responsive 3D-Models For Any Device](https://developer.mozilla.org/en-US/demos/detail/responsive-3d-models-for-any-device)

[Spriting with CSS Media Queries](https://developer.mozilla.org/en-US/demos/detail/spriting-with-css-media-queries)

Thanks to everyone that participated in the October Dev Derby! Only a couple of days left to participate in the [November Dev Derby](https://developer.mozilla.org/en-US/demos/devderby#upcoming), so get your Canvas demos in now. Otherwise, start experimenting with IndexedDB for December.
