I just returned from a recording session with Microsoft for their [Channel 9](http://channel9.msdn.com/) feature. Rey Bango (ex-Mozilla and also ex-Ajaxian) had invited us to chat about a few web development topics on video. The recordings are being edited now but you can get the presentations and the code examples right now.

![Rey and Chris](../../assets/51c7dbdf6f9cf0b1.jpg)


The first session we recorded was about “Building for real standards”. In this we talk about what a standard means, how this applies to HTML5 and discuss problems and pitfalls to avoid. The slides are [available on Slideshare](http://www.slideshare.net/cheilmann/building-for-real-standards-no-notes) and there is also [a version with presenter notes](http://www.slideshare.net/cheilmann/building-for-real-standards-includes-notes).

As part of the [Mozilla Evangelism Reps Program](http://hacks.mozilla.org/2012/04/launching-evangelism-reps-getting-the-army-of-awesome-ready-to-take-the-stage/) we also make the slides with presenter notes as PDF, Keynote and PPT available and additionally release the code examples with tips on how to present them.

You can get all of this [on GitHub](https://github.com/codepo8/buildingforrealstandards) in case you want to give this presentation yourself.

In the second (and last) part of the series we talked in detail about Progressive Enhancement, Graceful Degradation and Responsive design. The slides and code examples will be up here tomorrow.
