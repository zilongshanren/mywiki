[IndexedDB](https://developer.mozilla.org/en/IndexedDB) lets web applications store structured data for fast online and offline use. Data can be stored using key-value pairs, and values do not need to be serialized (as they do with document-oriented databases) or coerced into a relational structure (as with relational databases).

![](../../assets/8edf1f06addeed39.png)

[December Dev Derby](https://developer.mozilla.org/en-US/demos/devderby/2011/december/). Please join us in congratulating the top three demos as chosen by our judges.

![](../../assets/d7b2ceb61fb0caa4.png)

**1st Place: **[eLibri](https://developer.mozilla.org/en-US/demos/detail/elibri) by [mar.castelluccio](https://developer.mozilla.org/en-US/profiles/mar.castelluccio/)

**2nd Place: **[FileSystemDB ](https://developer.mozilla.org/en-US/demos/detail/filesystemdb)by [mar.castelluccio](https://developer.mozilla.org/en-US/profiles/mar.castelluccio/)

[Vurkout Buddy](https://developer.mozilla.org/en-US/demos/detail/vurkout-buddy) by [wcheung](https://developer.mozilla.org/en-US/profiles/wcheung/)
