It has been far too long since the last MDN online doc sprint. For those of you who have been asking me when the next sprint is (yes, there are a few), you need wait no longer. We’ll be holding a ![Better Web docs for a better web Better Web docs for a better web](../../assets/098fb4bbcf809189.png)


[sprint to work on MDN docs next Friday and Saturday, January 20 and 21](https://wiki.mozilla.org/MDN/Doc_sprints/2012January). Mark it on your calendar:

![](https://www.google.com/calendar/images/ext/gc_button1_en.gif)


![](https://www.google.com/calendar/images/ext/gc_button1_en.gif)

(For those who don’t know what a doc sprint is, it’s a short period when we have a concentrated effort by a number of people to improve the documentation on MDN.)

You don’t have to write whole new articles (though that’s fantastic). You can also update existing articles, add code examples, or add browser compatibility info. Many articles are tagged as needing help.

You can participate from wherever you are. We use the #devmo channel on irc.mozilla.org to coordinate. See the [planning page on the wiki](https://wiki.mozilla.org/MDN/Doc_sprints/2012January) to read further details and share your ideas.

**There will be swag.** Make a non-trivial contribution during the sprint, and you can get an MDN t-shirt (or other swag if you don’t want a t-shirt). Given the short notice, you might not be able to participate during the sprint. In that case, [contact me on Twitter](https://twitter.com/jmswisher), and I’ll consider contributions made outside of the sprint time frame for swag giveaways as well.
