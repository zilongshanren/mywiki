The latest Firefox 4 Beta has just been released (get it [here](http://firefox.com/beta)). This beta comes with [hundreds of bug fixes](https://bugzilla.mozilla.org/buglist.cgi?resolution=FIXED,VERIFIED&chfieldfrom=2010-08-04%2010%3A30&chfield=resolution&query_format=advanced&chfieldto=2010-08-16%2012%3A00&product=Core&product=Firefox&product=NSPR&product=NSS&product=Toolkit), [Firefox Sync and Firefox Panorama](http://blog.mozilla.com/blog/2010/08/24/firefox-4-beta-updated-with-sync-and-panorama/). Here is a quick overview of the new features for web developers.

- Firefox now supports the HTML5 video
[“buffered” property](https://hacks.mozilla.org/2010/08/html5-video-buffered-property-available-in-firefox-4/); - HTML5 video “autobuffer” has been replaced with
[“preload”](https://hacks.mozilla.org/2010/08/video_preload_attribute/); - An experimental API is included to provide
[more efficient Javascript animations](https://hacks.mozilla.org/2010/08/more-efficient-javascript-animations-with-mozrequestanimationframe/); - An experimental CSS extension:
[drawing arbitrary elements as backgrounds with -moz-element](http://hacks.mozilla.org/2010/08/mozelement); - Increase default disk cache size from 50M to 250M (
[bug](https://bugzilla.mozilla.org/show_bug.cgi?id=193911)); - Faster access to some DOM properties (.id, .className, .style, …) (see bugs
[584287](https://bugzilla.mozilla.org/show_bug.cgi?id=584287)and[584293](https://bugzilla.mozilla.org/show_bug.cgi?id=584293)).
