Firebug 1.5 was [released yesterday](http://hacks.mozilla.org/2010/01/firebug-1-5-released/) on addons.mozilla.org, where you can now [download it](http://bit.ly/8BbZFz). It’s compatible with the [upcoming Firefox 3.6](http://bit.ly/8a0Kux).

If you’d like to take a more in-depth look at what’s new in Firebug 1.5, here’s a series of articles written by Firebug contributor [Jan Odvarko](http://www.softwareishard.com/blog/category/firebug/) (aka Honza):

[Break On Next](http://www.softwareishard.com/blog/firebug/firebug-15-break-on-next/): breaking on the next executed script, HTML mutation, XHR execution, or JavaScript error.[XHR breakpoints](http://www.softwareishard.com/blog/firebug/firebug-15-xhr-breakpoints/): creating conditional breakpoints in XMLHttpRequest execution.[Debugging cookies](http://www.softwareishard.com/blog/firebug/new-firebug-15-debugging-cookies/): using the Firecookie extension to break JS execution on cookie changes.[Page load analysis](http://www.softwareishard.com/blog/firebug/page-load-analysis-using-firebug/): 6 examples analyzing data provided by the Net panel.[HTTP Time Monitor](http://www.softwareishard.com/blog/firebug/firebug-http-time-monitor/): using Network Activity Observer for more accurate timing.[XML Response Explorer](http://www.softwareishard.com/blog/firebug/xml-explorer-for-firebug/): inspecting XML based responses received from the server.[Network info header and column customization](http://www.softwareishard.com/blog/firebug/firebug-net-panel-column-customization/): specifying what information to display within the Net panel.

If you’ve had a chance to try the [new Firebug](http://bit.ly/8BbZFz), comment here or in the [Firebug newsgroup](http://groups.google.com/group/firebug/t/4cdca29c3cf5d7cb) and tell the team what you think!
