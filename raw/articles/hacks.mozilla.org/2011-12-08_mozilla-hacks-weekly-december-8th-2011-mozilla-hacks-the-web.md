Thursday is here, and just like every week when that day comes, we at Mozilla want to share some good reading with you.


## Weekly links December 8th 2011

If there is anything you think we should read or know about, don’t hesitate to post a comment, contact us on Twitter or through any other mean.

The picks this week are:

### Christian Heilmann

![](../../assets/73c300a3a9b62fcb.jpg)

[3D CSS Tester](http://thewebrocks.com/demos/3D-css-tester/)is a small tool I put together yesterday to make it easier to understand 3D transforms in CSS3.

If you want to read more tips or discuss the web with Christian, he’s available on Twitter as [@codepo8](http://twitter.com/codepo8).

### Eric “Sheppy” Shepherd

![](../../assets/fe6c559a2b55cf87.jpg)

[switching to clang for building Firefox](http://ehsanakhgari.org/blog/2011-10-18/why-you-should-switch-clang-today-and-how). Check out ehsan’s blog post on how to do this.

If you want to read more tips or discuss the web with Eric, he’s available on Twitter as [@sheppy](http://twitter.com/sheppy).

### Havi Hoffman

![](../../assets/b2d68053fc6219be.jpg)

[NewGameConference Youtube channel](http://www.youtube.com/user/NewGameConference#p/), including a talk about

[Paladin](http://www.youtube.com/watch?v=pA9d2PqebPk&feature=channel_video_title), Mozilla’s 3D gaming framework.

Havi can be found on Twitter as [@freshelectrons](http://twitter.com/freshelectrons)

### Jay Patel

![](../../assets/402b2a9c4e683601.jpg)

[with a forecast of 1 billion by 2013](http://techcrunch.com/2011/12/07/forecast-1-billion-html5-phones-by-2013/), the future of apps built on Web technologies is looking bright.

If you want to read more tips or discuss the web with Jay, he’s available on Twitter as [@jaybhai](http://twitter.com/jaybhai)

### Jean-Yves Perrier

![](../../assets/bd1c014280c81573.png)

[How to bulletproof @font-face web fonts?](http://sixrevisions.com/css/font-face-web-fonts-issues/)

If you want to read more tips or discuss the web with Jean-Yves, he’s available on Twitter as [@teoli2003](http://twitter.com/@teoli2003).

### Jeff Griffiths

![](../../assets/bd4bec74987fbf61.jpg)

[csg.js](http://evanw.github.com/csg.js/), enabling even guys like me to make cool webgl cubes and spheres with simple JS code.

If you want to read more tips or discuss the web with Jeff, he’s available on Twitter as [@canuckistani](http://twitter.com/canuckistani).

### Rob Hawkes

![](../../assets/bf1d2a9fda8c5762.jpg)

[how open-sourcing the game while it’s still popular has been a win-win situation](http://blog.semisecretsoftware.com/open-sourcing-your-game-while-its-still-popul)for them. It’s nice to hear success stories about open game development rather than the (usually unfounded) fears about IP and easily-accessible code.

If you want to read more tips or discuss the web with Rob, he’s available on Twitter as [@robhawkes](http://twitter.com/robhawkes).

### Robert Nyman

![](../../assets/520e1af8dc948590.jpg)

[Adaptive Images for Responsive Design](http://24ways.org/2011/adaptive-images-for-responsive-designs-again)is quite interesting from a hacking perspective, but also very important in displaying the lack of options in web browsers today when it comes to building more versatile designs.

If you want to read more tips or discuss the web with Robert, he’s available on Twitter as [@robertnyman](http://twitter.com/robertnyman).

### Tristan Nitot
