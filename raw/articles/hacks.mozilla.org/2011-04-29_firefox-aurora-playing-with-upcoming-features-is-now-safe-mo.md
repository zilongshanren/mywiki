[Firefox Aurora](http://firefox.com/channel) is a preview of the next version of Firefox, released every six weeks. It provides a safe way to play with the latest Web technologies the Mozilla team is working on.

### What is Aurora?

Aurora is a new preview version that fits between the Nightly builds and Betas:

- Firefox Nightly (
[firefox.com/channel](http://firefox.com/channel)) is released every day and includes the latest (potentially unstable) features and patches. - Firefox Aurora (
[firefox.com/channel](http://firefox.com/channel)) is released every six weeks and includes the newest features not known to cause problems. - Firefox Beta (
[firefox.com/channel](http://firefox.com/channel)) is released every six weeks and includes the features that are ready to be used and be tested by a large audience.

![Illustration of the release cycle](../../assets/0d2ae6e2987628aa.png)


### Should I use Aurora?

Amongst other things, Aurora already lets you play with CSS3 Animations and the new tabs management of Firefox. You can help us debug and test these features simply by installing Aurora from [firefox.com/channel](http://www.firefox.com/channel/).

### Switching between channels

Once you have [downloaded and installed Aurora](http://www.mozilla.com/en-US/firefox/channel/), you can switch to other channels at will. Simply click on the **Help** menu and open the **About** window.

![Screenshot-About Aurora1 Aurora About window](https://hacks.mozilla.org/wp-content/uploads/2011/04/Screenshot-About-Aurora1-500x282.png)


**Update**: The channel switcher will be removed from future versions of Aurora as [explained](http://blog.mozilla.com/channels/2011/06/02/update-on-channel-switcher/) by Johnathan Nightingale on the channels blog.

Start using it right away and let us know what you think about it.
