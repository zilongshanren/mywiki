[BrowserID](https://browserid.org/) is an initiative to provide the web with a better way to sign in. The web is a connected collection of resources and you should not have to have a user name and password for each of them when you could use the web instead.

Today we show you a screencast of how easy BrowserID makes it to login to a web site. For this, we’ll look at how the login flow for an existing BrowserID user works the first time they log in on a new website. Our example website is [OpenPhoto](http://current.openphoto.me/), a hot new photo sharing app that keeps users in control of their data.
