It has been a slow couple of weeks for MDN doc changes, due to the holidays. However, a few things of note have happened.

## Web standards docs

**Jean-Yves Perrier**continues working through the[CSS reference](https://developer.mozilla.org/en/CSS_Reference). Now up to the letter F (font-*)!**Jesper Kristensen**added a browser compatibility table to[Media formats supported by the audio and video elements](https://developer.mozilla.org/En/Media_formats_supported_by_the_audio_and_video_elements).**Kevin Lim**started pages for[File APIs](https://developer.mozilla.org/en/DOM/File_APIs)and created the reference docs for the[FileSystem API](https://developer.mozilla.org/en/DOM/File_API/File_System_API)(one of the File APIs). She also wrote the first draft of an expository article:[Basic concepts about the filesystem API](https://developer.mozilla.org/en/DOM/File_APIs/Filesystem/Basic_Concepts_About_the_Filesystem_API).**Thomas Bilk**created a page for[HTML <nobr>](https://developer.mozilla.org/en/HTML/Element/nobr).- During the first “Mercredi Doc” session of 2012 at the Mozilla Paris office, several pages were translated into French:
**Julien W**translated[JavaScript Shells](https://developer.mozilla.org/fr/JavaScript/Shells).**Fred Bourgeon**translated[CSS animation](https://developer.mozilla.org/fr/CSS/animation)and created a French version of the SeeCompatTable macro.**Timothée Carry-Caignon**started translating[How to write forward-compatible websites](https://developer.mozilla.org/index.php?title=fr/D%C3%A9veloppement_Web/D%C3%A9velopper_des_sites_%C3%A0_compatibilit%C3%A9_descendante).

- During Mercredi Doc,
**Jeremie Patonnier**also documented the[SVG fill-opacity attribute](https://developer.mozilla.org/en/SVG/Attribute/fill-opacity).

## Mozilla-specific docs

**Eric Shepherd** created an article on [Updating add-ons for Firefox 10](https://developer.mozilla.org/en/Firefox/Updating_add-ons_for_Firefox_10).

Thanks to everyone for their contributions in 2011, and we look forward to more improvements to the documentation on MDN in 2012.
