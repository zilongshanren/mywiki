Tristan Nitot wrote a blog post describing how [MDN does documentation the Mozilla way](http://blog.mozilla.com/beyond-the-code/2012/03/30/mdn-documentation-the-mozilla-way/). It also gives a good summary of ways that you can help out.

## Upcoming events

Plans are proceeding for the next [MDN documentation sprint, April 27 to 29](https://wiki.mozilla.org/MDN/Doc_Sprints/2012April). The first day (Friday) will be the Mozilla office in Mountain View, California, and the weekend days will be in the San Francisco office. If you’re in the San Francisco Bay Area, and you’d like to join us on any of those days, you’re definitely welcome. Just [contact me](mailto:jswisher@mozilla.com) to let me know. If you’re located elsewhere, you’re welcome to join us remotely.

Work is proceeding apace on [Kuma](https://wiki.mozilla.org/MDN/Kuma), the new wiki platform that our splendid WebDev team is creating for MDN. We will be holding a test day on Friday, April 20, to bang on it on a staging server. If you’re a regular writer, editor, or localizer on MDN, we’d appreciate your help. Details about that event are forthcoming.

## Doc updates

Here is a sampling of doc changes that have been made in the past couple of weeks.

### Web standards docs

**Andrew Ardill**cleaned up the code samples in the[Functions section of the JavaScript Guide](https://developer.mozilla.org/en/JavaScript/Guide/Functions).**Brian Brennan**did lots of clean-up and formatting in the[CSS Reference](https://developer.mozilla.org/en/CSS/CSS_Reference).**Drublic**expanded and improved[window.setImmediate](https://developer.mozilla.org/en/DOM/window.setImmediate).**Havvy**added a code example to the[JavaScript freeze() method](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/Object/freeze).**Patrick Kettner**added a compatibility table and info to[<wbr>](https://developer.mozilla.org/en/HTML/Element/wbr).**Mykura**added a constructor section and a section on the history of slice() implementations to[Blob](https://developer.mozilla.org/en/DOM/Blob)and updated and improved[XMLHttpRequest](https://developer.mozilla.org/en/DOM/XMLHttpRequest).**Masayuki Nakano**added a table showing how to activate ‘accesskey’ on various browsers to[HTML global attributes](https://developer.mozilla.org/en/HTML/Global_attributes).**Andreas Nilsson**added a browser compatibility table to[Date toLocaleString](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/Date/toLocaleString).**Jérémie Patonnier**created pages for the SVG attributes[filterUnits](https://developer.mozilla.org/en/SVG/Attribute/filterUnits)and[primitiveUnits](https://developer.mozilla.org/en/SVG/Attribute/primitiveUnits).**Jean-Yves Perrier**expanded[::first-line](https://developer.mozilla.org/En/CSS/%3A%3Afirst-line), added information about language-specific cases to[text-transform](https://developer.mozilla.org/en/CSS/text-transform), and added browser compatibility and language-specific cases to[font-variant](https://developer.mozilla.org/en/CSS/font-variant).**Nickolay Ponomarev**reorganized the spec information in the[DOM event reference](https://developer.mozilla.org/en/DOM/DOM_event_reference")and updated and improved[HTMLMediaElement](https://developer.mozilla.org/en/DOM/HTMLMediaElement).**Florian Scholz**created pages for[::-moz-page](https://developer.mozilla.org/en/CSS/%3A%3A-moz-page),[::-moz-page-sequence](https://developer.mozilla.org/en/CSS/%3A%3A-moz-page-sequence), and[::-moz-scrolled-page-sequence](https://developer.mozilla.org/en/CSS/%3A%3A-moz-scrolled-page-sequence); updated[MathML maction](https://developer.mozilla.org/en/MathML/Element/maction); and added a browser compatibility table and spec link to[window.navigator.vibrate](https://developer.mozilla.org/en/DOM/window.navigator.vibrate)and[MathML merror](https://developer.mozilla.org/en/MathML/Element/merror).**Rob W**expanded and added a spec link to[Using Web workers](https://developer.mozilla.org/En/Using_web_workers).**Ziyunfei**updated a bunch of Chinese translations, including[JavaScript strict mode](https://developer.mozilla.org/zh-cn/JavaScript/Strict_mode),[HTTP response codes](https://developer.mozilla.org/zh-cn/HTTP/HTTP_response_codes),[window.prompt](https://developer.mozilla.org/zh-cn/DOM/window.prompt),[Array forEach](https://developer.mozilla.org/zh-cn/JavaScript/Reference/Global_Objects/Array/forEach), and[String replace](https://developer.mozilla.org/zh-cn/JavaScript/Reference/Global_Objects/String/replace).

### Mozilla technology docs

**Archeopteryx**added a reference page for the[browser.altClickSave](https://developer.mozilla.org/en/Preferences/Preferences_reference/browser.altClickSave)preference.**Will Bamberg**created an[FAQ page for BrowserID](https://developer.mozilla.org/en/BrowserID/FAQ).**David Bienvenu**wrote an article on[Thunderbird file link providers](https://developer.mozilla.org/en/Thunderbird/File_Link_Providers).**Darktrojan**updated[code snippets for preferences](https://developer.mozilla.org/en/Code_snippets/Preferences).**Benoit Girard**added a screenshot to[Profiling with the built-in profiler](https://developer.mozilla.org/en/Performance/Profiling_with_the_Built-in_Profiler).

### Mozilla project docs

**Joey Armstrong**updated[Coding style](https://developer.mozilla.org/En/Developer_Guide/Coding_Style)in the Developer Guide.**Jeff Beatty**created a page about[Localization technical reviews](https://hacks.mozilla.org/created a page about https:/developer.mozilla.org/en/Localization_technical_reviews).**Anthony Hughes**added a section on transplanting a patch to[Mozmill tests](https://developer.mozilla.org/en/Mozmill_Tests).**Josh Matthews**updated[How to submit a patch](https://developer.mozilla.org/En/Developer_Guide/How_to_Submit_a_Patch).
