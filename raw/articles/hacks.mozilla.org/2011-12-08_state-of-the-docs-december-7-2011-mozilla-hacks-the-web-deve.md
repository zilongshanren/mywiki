### Updated docs

**Marcoos** updated [document.importNode](https://developer.mozilla.org/en/DOM/document.importNode) for DOM4, added browser compatibility tables to [Node.parentNode](https://developer.mozilla.org/en/DOM/Node.parentNode), [window.home](https://developer.mozilla.org/en/DOM/window.home) and [CSS :hover](https://developer.mozilla.org/en/CSS/:hover); and updated compatibility info on several other pages.

**martijnetje** added a compatibilty note about JScript to the [String.substr](https://developer.mozilla.org/en/JavaScript/Reference/Global_Objects/String/substr).

**fusionchess** added examples for the [JavaScript ‘for’ statement](https://developer.mozilla.org/en/JavaScript/Reference/Statements/for), for [window.location](https://developer.mozilla.org/en/DOM/window.location), and for [Using XMLHttpRequest](https://developer.mozilla.org/en/DOM/XMLHttpRequest/Using_XMLHttpRequest).

## Mozilla project docs

**Kyle Huey** updated the [Windows prerequisites for the build instructions](https://developer.mozilla.org/En/Developer_Guide/Build_Instructions/Windows_Prerequisites) and the [pymake](https://developer.mozilla.org/en/pymake) page, and created a simplified [XPCOM hashtable guide](https://developer.mozilla.org/en/XPCOM_hashtable_guide).

**Jeff Beatty** has been beefing up the information to assist Firefox localizers, such as the [Localization Quick Start Guide](https://developer.mozilla.org/en/Localization_Quick_Start_Guide).

**Mark Banner** updated the page on [Thunderbird localization](https://developer.mozilla.org/en/Thunderbird_Localization), and created one on [productizing Thunderbird localizations](https://developer.mozilla.org/en/Thunderbird_Localization/Productization).

**Nicholas Nethercote** wrote an article on [Zombie compartments](https://developer.mozilla.org/en/Zombie_compartments).

## New staff

Long-time MDN contributor **Jean-Yves Perrier** has joined Mozilla’s Developer Engagement team as a technical writer, expanding the paid writing staff of MDN to three people. Located in Switzerland, he’ll continue working on docs for open Web standards and help keep MDN up to date with changes in Firefox. You’ll find Jean-Yves on IRC as teoli, and you can follow him on Twitter as [@Teoli2003](https://twitter.com/Teoli2003). Welcome!
