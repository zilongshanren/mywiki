# Chips and Cheese's Microbenchmark Framework

### A Call to Action for Code Contributors

Hello you fine Internet folks!

Back in May of this year, we had a [Call to Action](https://chipsandcheese.com/p/chips-and-cheese-state-of-the-union) where we talked about setting up a new microbenchmark framework. This framework was meant to allow for standardization between different tests to allow for consistency between tests in the short term. And with the long term goal being that this would allow for folks in the Chips and Cheese community to add to the test suite at a rate that the Chips and Cheese team could write on its own. This would also diversify the number of folks writing tests and allow Chester to become an Editor-in-Chief for the Chips and Cheese benchmark suite as it grows and expands.

To expand on the long term goal, we hope that there won’t just be tests that measure different parts of the silicon but also to have multiple tests that test the same thing just with different methodologies so that we can cross check and validate results.

Well today I am happy to announce that we have published our framework thanks to the incredible work from Nintonito and Lillith Beatrix!

Link: [https://github.com/ChipsandCheese/CnC-Tools/tree/main](https://github.com/ChipsandCheese/CnC-Tools/tree/main)

But that’s not all, Nintonito and Lillith Beatrix have also been working on getting some of Chester’s tests moved over to the new framework and the first test in that move is the ever-popular Core Coherency tests which is about 90% through the move to the new framework as of the time of writing.

This moving our goal of providing more tools for the community to use forward but we can’t do that alone. You can consider this a second Call to Action for Code Contributors. We hope that you the community will be inspired by this framework to design and write your own tests. If you are inspired to create code for this framework then please feel free to join the [Discord](https://discord.gg/TwVnRhxgY2) and chat with the folks behind the scenes.

And to end this announcement, I will be at Supercomputing 2024 in Atlanta so if you happen to see me, feel free to come up and say hello to me!

Have a great one folks!
