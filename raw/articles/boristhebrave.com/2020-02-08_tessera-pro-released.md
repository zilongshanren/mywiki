Due to demand, I’ve now released [Tessera Pro](https://assetstore.unity.com/packages/tools/modeling/tessera-pro-161077), an upgraded version of [Tessera](https://assetstore.unity.com/packages/tools/modeling/tessera-procedural-tile-based-generator-155425) which comes with source code and some extra features. Hopefully with more features to come.

I’m really pleased with how the project has been recieved so far, and am hoping to see some awesome games made with it.

Check it out on [the Unity asset store](https://assetstore.unity.com/packages/tools/modeling/tessera-pro-161077).
