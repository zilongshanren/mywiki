I’ve released a Python based string parser on [GitHub](https://github.com/BorisTheBrave/axaxaxas). This was part of a much more ambitious project that fell through, but I extracted the good part.

Axaxaxas is a Python 3.3 implementation of an [Earley Parser](https://en.wikipedia.org/wiki/Earley_parser). Earley parsers are a robust parser that can recognize any context-free grammar, with good support for amiguous grammars. They have linear performance for a wide class of grammars, and worst case .


The main goals of this implementation are ease of use, customization, and requiring no pre-processing step for the grammar. You may find the [Marpa](https://jeffreykegler.github.io/Marpa-web-site/) project better suits high performance needs.

Documentation can be found at: [http://axaxaxas.readthedocs.org](http://axaxaxas.readthedocs.org)
