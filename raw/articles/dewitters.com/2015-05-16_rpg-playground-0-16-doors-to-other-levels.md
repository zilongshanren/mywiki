You probably have been waiting for this release. Previous time you were able to [create new levels](http://www.koonsolo.com/news/rpg-playground-0-15-multiple-levels/), but not yet for your hero to walk into them. Well, head over to [http://rpgplayground.com](http://rpgplayground.com), because now you can add doors to go to other levels.

- A real door where you always stay beneath it, and which opens with an animation sequence when walking into it.
- A portal that you need to walk onto.

Both of these door types also have an invisible variant.

As already mentioned in a previous blog post, the game will now be [paused when going to edit mode](http://www.koonsolo.com/news/your-game-will-always-be-paused-in-edit-mode/).

Remark that in this release I changed a lot of internals of my engine, so if you see things that don’t work (anymore), or some crazy stuff happening, let me know a.s.a.p. .

Now go and [create some cool levels](http://rpgplayground.com)!
