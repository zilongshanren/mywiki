Are you one of those people with fond memories of playing *The Legend of Zelda*? The whole action-adventure game genre was defined by that game, and it was the inspiration for many other action role playing games that followed it.

![](../../assets/1082a680b1bfab74.png)


Even today, many game developers are inspired by Zelda, and base their games on similar game play. Examples are [Anodyne](http://www.anodynegame.com/), [Midora](https://www.kickstarter.com/projects/1867607597/midora-0), [Hyper Light Drifter](https://www.kickstarter.com/projects/1661802484/hyper-light-drifter), [Delver’s Drop](http://delversdrop.com/), [Across Age](http://gameslikefinder.com/across-age/), [The Binding of Isaac](http://bindingofisaac.com/) and many more.

Creating such a game seems daunting, but it really isn’t. As a matter of fact, there are many options available on how to create your own Zelda-like game. I will give you the complete overview here.


## Open Zelda

[Open Zelda](http://openzelda.net/) is open source editor in which you can make games in the style of [A Link to the Past](https://en.wikipedia.org/wiki/The_Legend_of_Zelda%3A_A_Link_to_the_Past). It’s made up of 3 programs: the player, quest designer and content package. The player is basically that program that runs the game. The quest designer contains a sprite and tilemap editor, and allows scripting. And finally the content package contains various scripts and media used by the game.

A nice benefit is that it runs on multiple platforms: Windows, Mac OS X and Linux.

Open Zelda used to have a big community, but unfortunately it seems to be fading away.

## Zelda Classic

![SotW20_ChrisMiller_zps6b502881.png](../../assets/fec18f11b634ffae.png)


The first build of [Zelda Classic](http://www.zeldaclassic.com/) dates all the way back to 1999. It was initially developed with the intent to create an exact replica of the NES version of The Legend Of Zelda.

But the current version is far from limited to it! New quests, items, enemies, etc. can be created. Even custom graphics can be used, as long as they are in 8-bit color. Next to the typical top-down visual style, side-view platform games can also be made with it.

Supported platforms are Windows, Mac OS X and Linux. And if you really feel nostalgic, the older DOS versions are still available for download.

## Solarus

[Solarus](http://www.solarus-games.org/) is an open-source Action-RPG engine. The [Solarus Quest Editor](http://www.solarus-games.org/engine/solarus-quest-editor/) allows you to edit maps, sprites, tilesets, dialogs, scripts, musics and sounds. The LUA scripting language is used for scripting. It’s nice to see that this editor is still actively being updated.


![](http://www.solarus-games.org/wp-content/uploads/2015/05/sprite-editor.png)


Supported platforms are Windows, Mac OS X and Linux.

## RPG Maker with an ABS script

While [RPG Maker](http://www.rpgmakerweb.com/) itself doesn’t contain action style combat, there is a way to add it. So called *Action Battle System* scripts can be used to extend RPG Maker to feature action fighting. Here’s a list of such scripts:

[XAS Hero Edition](http://rpgmaker.net/games/2517/)for RPG Maker XP (RMXP)[Pearl ABS Liquid](https://falcaorgss.wordpress.com/category/pearl-abs-liquid/)for RPG Maker VX Ace[Sapphire Action System](http://forums.rpgmakerweb.com/index.php?/topic/4918-sapphire-action-system-iv/)for RPG Maker VX Ace

Unfortunately this is for MS Windows only, but with some effort you can [port your RPG Maker game to other platforms](http://www.koonsolo.com/news/exporting-rpg-maker-games-to-iphone-android-or-other-platforms/).
