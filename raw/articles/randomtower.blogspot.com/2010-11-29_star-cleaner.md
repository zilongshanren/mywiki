[StarCleaner](http://www.rightanglegames.com/starcleaner/index.html)is a little platformer created by

[RightAngleGames](http://www.rightanglegames.com/). Thomas (tommy on slick forum) decided to build a simple, little platformer in Java and obviously decided to use

[Slick](https://randomtower.blogspot.com/slick.cokeandcode.com).

Main idea for this game is that player control a little angel and need to collect all stars and then go back to sun or moon. Game is fun because you need to remember level structure when is day and then night (see screenshot!) jump around.

Well done!

He decided to use my

[MarteEngine code on Github](http://github.com/Gornova/MarteEngine), inspired from experience with[Flashpunk](https://randomtower.blogspot.com/flashpunk.net)in my last games. As he said on his[blog](http://www.rightanglegames.com/blog/index.html), working with code from[Advanced Platform Engine](http://flashpunk.net/forums/index.php?topic=738.15)ported to Slick was really easy, and I'm happy too, because he send to me StarCleaner code, so this code will be merged into MarteEngine. Stay tuned!Power of opensource :D
