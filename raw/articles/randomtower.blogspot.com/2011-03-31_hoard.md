I've discovered this rare game only today!

[Hoard](http://www.hoardgame.com/)is a game about a dragon: you!

Game rules are pretty simple: dragons loves golds, so there is a challenge between them to be "gold ruler". So.. collect gold!

Where found gold? From castles, villages, caravans..

How can this be done? Burning everything!! This is main game rule!

Game is fun, fast and easy to learn.. and have multiplayer.. you must try it!!
