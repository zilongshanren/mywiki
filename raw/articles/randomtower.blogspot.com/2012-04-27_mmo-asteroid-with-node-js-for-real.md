It's incredible how much effort and work goes to innovative way to use the web.

[Node.js](http://nodejs.org/)is and incredible piece of software and helps real company to solve real problems. This is a blog about my efforts in game developmen so I'm game centric right now.

Today I'll present you a nice work: a Massive Multiplayer Online game, based on asteroid. You can play it

[here](http://seb.ly/demos/MMOsteroids.html), in your browser.

A better explanation how things working is

[here](http://seb.ly/2012/04/node-js-experiment-mmo-asteroids/)

You can see the trick? Maybe not, because it's an

[April fool](http://seb.ly/2012/04/gotcha-fake-mmo-asteroids-april-fool/):D

But think for a moment: we can think in a not so distant future a game based on node.js with speed and quickness of

[Realm of mad god](http://www.google.it/url?sa=t&rct=j&q=&esrc=s&source=web&cd=1&sqi=2&ved=0CDIQFjAA&url=http%3A%2F%2Fwww.realmofthemadgod.com%2F&ei=HruOT_XXBJHMtAb69MisCQ&usg=AFQjCNHQ2X1rH3q6EZcIWLicJLZ2osYllw)?

I think is possible: as software and web developer I can see how much work is in this area and more important, despite some rapid cycle of development of major browsers (Chrome and Firefox), standard are rising, finally!
