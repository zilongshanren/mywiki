MarteEngine (

ME) is a Java videogame engine with it's focus on a simple, clean API for fast game development.

Major inspiration comes from ([Flashpunk](http://flashpunk.net/)) and ([Slick forum](http://slick.javaunlimited.net/)).

Authors are [Alberto "Gornova" Martinelli](http://randomtower.blogspot.com) and [Thomas "Tommy" Haaks](http://www.rightanglegames.com)

**Features**

-
**entity based framework**: everything in your game is an Entity, many things are already coded, no reinventing the wheel anymore!- basic physics
- collision detection
- a standard way to organize your project

-
**manipulate your entities**: rotate, scale, animate using tweens, -
**examples! Ready to play and easy to learn!**(click to play!):

-
**distribuite your game**: windows exe, webstart, applet all done using ready-to-run[ant](http://ant.apache.org/)tasks, fast and easy -
**based on proven libraries**:[Slick](http://slick.cokeandcode.com/)and[Lwjgl](http://www.lwjgl.org/)
