Thomas point me into two article (

[om his blog](http://www.rightanglegames.com/blog/index.html)), with some nice points: tool is ready to develop new game and integration with existings services (Facebook for example) are en route.

It's time to develop a game with HTML5 using

[GameMaker](http://www.yoyogames.com/gamemaker/html5)?

Not yet..

GameMaker is out at 99$ but other tools, like Construct2 are 32$ (

[with early adopter license](http://www.scirra.com/construct2/early-adopter)). My idea is not to use one tool before some great games are available.

For now there are some demos (

[here](http://html5.yoyogames.com/)and

[here](http://www.scirra.com/construct2/demos)), but where are greats HTML5 games? Other than

[Angry Birds](http://chrome.angrybirds.com/), of course!

Main question is: when a complete tool to design HTML5 games into

**our**browsers? Maybe

[Play My code solution](http://www.playmycode.com/)is the right way?
