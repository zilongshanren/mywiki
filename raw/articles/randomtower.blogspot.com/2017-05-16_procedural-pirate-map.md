I've found inspiring the

[Procedural pirate map monthly challenge on reddit](https://www.reddit.com/r/proceduralgeneration/comments/3vcbb3/monthly_challenge_1_dec_2015_procedural_pirate_map/), because as usual, folks surprise me with multiple way to solve a problem and use procedural generation in a unusual way.

Some highlight from this quality collection:

- Scallywag:
[source](https://github.com/wlievens/scallywag)and[demo](https://rawgit.com/wlievens/scallywag/master/index.html), I like so much the colors ( see image on the top) and shapes, a great work! - Lost heaven pirate map:
[blog post](http://blog.rakuen.tk/post/postmortem-pirate-map/), a nice explanation about tecnique behind the project, well done! - Polygonal map generation:
[blog post](http://www-cs-students.stanford.edu/%7Eamitp/game-programming/polygon-map-generation/)and[demo](http://www-cs-students.stanford.edu/%7Eamitp/game-programming/polygon-map-generation/), not pirate-related, but IMHO, the best explanation on how it's possible to generate a great island using Delaunay triangulation ( I've used this tecnique to build a galaxy in[Galaxy Artifacts](https://github.com/Gornova/GalaxyArtifacts))

Thanks guys! So much inspiration for future works! Amazing!
