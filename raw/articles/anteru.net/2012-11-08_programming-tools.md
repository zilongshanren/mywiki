By popular demand, here’s the list of tools and stuff I use regularly now:

- Visual Studio 2012 with a custom,
[solarized light](http://ethanschoonover.com/solarized)based color theme. I really like this a lot, and while it takes a while to get used to it, I find it hard to go back to high-contrast themes. Project files are all generated with[CMake](http://www.cmake.org/)of course. - My programming font is
[Source Code Pro](http://blogs.adobe.com/typblography/2012/09/source-code-pro.html). It’s super-easy to read, works fine at the sizes I like, and I can have a consistent look & feel on Windows, Linux and Mac OS X. - For serious scripting, I use
[Python 3](http://python.org/)together with[PyQt](http://www.riverbankcomputing.co.uk/software/pyqt/intro). In my applications however, I typically embed[Lua](http://lua.org)if I want to quickly try out stuff. - For UI, I’m using
[Qt](http://qt-project.org/)if it requires more than 5 widgets. If it’s super simple (read: Single button window), I might hack it together in C# and WPF, but I usually go for Qt or PyQt. - My text editor of choice is
[Sublime Text 2](http://www.sublimetext.com/)(and yes, I bought a license). I’m using the[DirectWrite font rendering](http://www.sublimetext.com/forum/viewtopic.php?f=3&t=5885)there and the CMake extension - For references, I use
[Zotero Standalone](http://www.zotero.org/). The storage is set to a[SkyDrive](https://skydrive.live.com/)drive, so it automatically synchronizes across all my machines for free. - For source code management, I use
[Mercurial](http://mercurial.selenic.com)only. On Windows, in the form of[TortoiseHg](http://tortoisehg.bitbucket.org/), on Linux as well, and on Mac OS X, I use[SourceTree](http://www.sourcetreeapp.com/). - For taking notes and quick sketches, I use a graphics tablet and
[MyPaint](http://mypaint.intilinux.com/). - Most graphics I need are done using
[Inkscape](http://inkscape.org/). Otherwise, it’s[Veusz](http://home.gna.org/veusz/), but I’m curious to try[matplotlib](http://matplotlib.org/). - For IM, I’ve recently switched from
[Pidgin](http://www.pidgin.im/)to[Instantbird](http://instantbird.com/). Instantbird is the basically the same, but I like the default theme a bit more, and it takes really a tiny amount of screen space. - For 3D graphics, I took the time to learn a bit more
[Blender](http://www.blender.org/). The learning curve is steep, but it’s definitely worth the trouble. The hardest part for me was to unlearn Maya, which I usually used, but with some time and pratice Blender is just as good for the little 3D modelling I need. For occasionally viewing a mesh, I use usually my own tools now, or, in rare cases,[MeshLab](http://meshlab.sourceforge.net/). - For screenshots, I’m completely sold on
[Screenshot Captor](http://www.donationcoder.com/Software/Mouser/screenshotcaptor/index.html). It can capture Aero windows with transparency and shadows, and just works. - For video recording, I use
[Microsoft Expression Encoder 4](http://www.microsoft.com/expression/products/EncoderPro_Overview.aspx)and[Fraps](http://www.fraps.com/)(yes, with license). For batch processing of images I use[ImageMagick](http://www.imagemagick.org/script/index.php), and for the video production it’s[Ava](https://github.com/anteru/ava)together with[FFMPEG](http://ffmpeg.org/). - Documentation is now all done with
[Sphinx](http://sphinx-doc.org/)and[Robin](https://bitbucket.org/reima/robin).

[Mindjet MindManager](http://www.mindjet.com/products/mindmanager/), as our university has some deal with them and we can get it for free. It seems pretty decent, but I’m not sure how much I’ll be using in in the end. It certainly has the feeling of “oh gosh, this boosts my productivity by 12053%” at first, but it might turn out to be to cumbersome to use in the long run.

Sublime text is probably the most significant change that came this year. I actually forced myself to use a different editor than before, just to learn something new, and so far, I’m really happy about that. The other big change was learning Blender a bit better. I’ve delayed this a lot, but this year, I sat down a few weekends to seriously model something with it. On the programming side, I’ve done a bit of Javascript and Lua this year as part of my “do something new” stuff. I expect to spend some more time with both languages next year, so getting accustomed to them doesn’t hurt.

That’s for the tool side this year. What I’m still looking for is [a better e-mail client](https://anteru.net/blog/2012/07/07/1894/), but the rest of the tools gets the work done. Well, and maybe a rewrite for Robin, to make it a bit faster and more robust.
