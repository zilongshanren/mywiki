A dear reader asked whether the [Ava](https://anteru.net/blog/2011/05/02/1695/) source code is public, and yes, it is now! Ava is a small video-processing tool I’ve been using for producing videos for publications (I have [already](https://anteru.net/blog/2010/11/08/945/) [blogged](https://anteru.net/blog/2011/05/02/1695/) everything interesting about it.) It took some time, but I finally came around to add a bunch of comments and slap the BSD license on it. You can grab it fresh from the [Mercurial repository](https://github.com/anteru/ava).

The tool itself is really really small, so please don’t expect [Nuke](http://www.thefoundry.co.uk/products/nuke/)/[Premiere](http://www.adobe.com/de/products/premiere.html) here :)
