# Greenlight update + streaming tomorrow

Hello!

**First:** I wanted to thank everyone for the amazing support you've shown so far. We're already over [24% funded](https://www.kickstarter.com/projects/et1337/lemma-first-person-parkour), which is more than I was expecting this early, so thank you!

**Second:** A quick update on the [Greenlight campaign](http://steamcommunity.com/sharedfiles/filedetails/?id=239551444). We are 26% of the way to the top 100, with 1,918 "yes" votes! Keep on voting, we'll be on Steam in no time.

**Third:** If you wanted to see more gameplay from Lemma but didn't have time to check out the demo, several YouTubers have posted "let's play" videos of the demo. Draegast has [a good one right here](https://www.youtube.com/watch?v=yAcIkPEVghY).

**Fourth:** Although I am busy promoting the game, development continues. You can actually track my progress on [GitHub](https://github.com/et1337/Lemma) since the engine is open source. You may have seen the "power" system in the demo, where the blue material you create can actually transmit power from a power source. In the demo it was really only used to trigger explosives, but yesterday I built a new "switch" object which can trigger other things like elevators.
