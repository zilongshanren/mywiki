Restricts the number of discrete color values that can be displayed for each color channel.

# Posterize

**Enabled**- Should the effect be rendered?**Red Levels**- Number of possible red color values.**Green Levels**- Number of possible green color values.**Blue Levels**- Number of possible blue color values.**Power Ramp**- Modifies the input color values using a power curve. Higher values favor a darker output.
