The Outline (Sobel) effect runs a Sobel edge-detection kernel over the image.

![Sobel Outlines](../../assets/b80c6551e5b24390.jpg)


# Parameters

**Enabled**- Is the effect active?**Threshold**- How sensitive the edge-detection algorithm is.**Outline Color**- Color to use for edge pixels.**Background Color**- Color to use for all non-edge pixels. If you make this color transparent, the original image will appear underneath the outlines.
