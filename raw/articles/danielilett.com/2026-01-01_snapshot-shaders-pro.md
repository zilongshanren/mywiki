*Snapshot Shaders Pro* is a collection of post processing effect for the Universal Render Pipeline, High Definition Render Pipeline, and the built-in render pipeline. It’s compatible with Unity 2022.3 and above.

This asset pack adds 34 new post processing effects, plus variants, including **Outline**, **Dither**, **Oil Painting**, **Synthwave**, **Silhouette**, and more!

Use the menu button on the left to navigate through each effect in the pack.

# ✨ Features

*Snapshot Shaders Pro* is designed mainly for PC game usage. While some effects may work in VR or on mobile, they might be quite expensive (expecially on standalone VR), so I recommend using them sparingly on these platforms.

I made this pack because I wanted a set of plug-and-play image effect shaders which could easily slot into any game using Unity’s built-in features. It evolved into the asset pack you see today, with dozens of effects and support for all of Unity’s pipelines.

## 📦 Works out of the box with volumes

Each effect in the pack can be attached to a volume profile and added to any volume in your scene. The effects start off in a neutral state, so just override the effect parameters and see the shaders come to life!

## 📚 Stackable effects

Many of the effects can stack with one another. If you want to create a low-fi security camera, combine the **Pixelation**, **Colorize**, and **Scanlines** effects to overlay a green tint with scrolling scanlines, with an added **Barrel Distortion** effect if you want to make a CRT screen. Or perhaps you’re looking for an old-timey film look, in which case, try a **Sepia Tone** filter with **Noise Grain** and a low amount of **Blur**.

## 🛠️ Customizable with tons of options

Each effect comes with a plethora of settings and parameters which you can tweak, which makes them highly flexible.
