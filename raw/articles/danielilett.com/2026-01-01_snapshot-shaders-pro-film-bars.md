Fits the viewport to a desired aspect ratio and displays black bars above and below the viewport. Great for cutscenes.

![Film Bars](../../assets/0e85769a194691f0.jpg)


# Parameters

**Aspect**- The desired aspect ratio of the viewport, represented by a single decimal value (width / height). Here is a quick guide to common aspect ratios and the values you should use:**12 : 5**- use 2.4**21 : 9**- use 2.333**16 : 9**- use 1.777**5 : 3**- use 1.666**3 : 2**- use 1.5**4 : 3**- use 1.333**5 : 4**- use 1.25
