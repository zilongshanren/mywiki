The installation process for *Retro Shaders Pro for Godot* is relatively straightforward. You will receive a zip file containing all the shader assets in the pack, with a folder called *Retro Shaders Pro* nested inside the *addons* folder. Please unzip the file and copy its contents into your own project’s *addons* folder.

Once the pack has been installed, each effect will be available to you in the Shaders folder, and there is a Demo scene with all the effects on display. There should be no additional configuration required.
