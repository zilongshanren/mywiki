An improved edge detection algorithm which can be altered to use image colours, depth or normals (or a combination).

![Outlines](../../assets/a7dc006270758253.jpg)


# Parameters

**Outline Colour**- The colour of the outlines.**Color Sensitivity**- The threshold for colour-based edge detection.**Color Strength**- The strength of colour-based edges, where detected.**Depth Sensitivity**- The threshold for depth-based edge detection.**Depth Strength**- The strength of depth-based edges, where detected.**Normal Sensitivity**- The threshold for normal-based edge detection.**Normal Strength**- The strength of normal-based edges, where detected.**Depth Threshold**- Pixels past this depth (normalised between 0 and 1) will not be edge-detected.
