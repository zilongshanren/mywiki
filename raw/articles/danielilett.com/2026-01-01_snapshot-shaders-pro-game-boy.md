Quantizes the image to four luminance values and tints the screen based on those values. Default values reflect those used by the original Game Boy.

![Game Boy](../../assets/1f2e1ff388fc07bc.jpg)


# Parameters

**Darkest**-The darkest colour, used by pixels with luminance between 0.00 and 0.25.**Dark**- The second darkest colour, used by pixels with luminance between 0.25 and 0.50.**Light**- The second lightest colour, used by pixels with luminance between 0.50 and 0.75.**Lightest**- The lightest colour, used by pixels with luminance between 0.75 and 1.00.
