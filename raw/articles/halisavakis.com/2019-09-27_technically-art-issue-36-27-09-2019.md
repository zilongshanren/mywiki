A quick guide to Lerp~✨

— Freya Holmér 🔜 IndieCade Europe (@FreyaHolmer)

Lerp is used to blend between two things!

It has three inputs: ( a, b, t )

a = start value

b = end value

t = how far we should go from start to end, as a percentage

Here it is in action!⚡blending a value, position, color and an angle![pic.twitter.com/LdA69fLI8N][September 23, 2019]

📏Lerp vs Slerp⭕

— Freya Holmér 🔜 IndieCade Europe (@FreyaHolmer)

• Lerp interpolates in a straight line

• useful for interpolating positions

• Slerp rotates around (0,0)

• useful for interpolating directions[#unitytips][pic.twitter.com/KSQQWCb5f4][September 23, 2019]
