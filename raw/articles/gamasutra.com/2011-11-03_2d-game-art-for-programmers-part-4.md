# 2D Game Art For Programmers - Part 4

This is the fourth set of tutorials using free graphic tools like inkscape and gimp to create 2D game art. While working on the animation tutorial I got a little sidetracked and created some more character designs.

![Game Developer Game Developer logo in a gray background | Game Developer](../../assets/de0d06fe69cb2dbe.png)

After the initial playing around with circles and squares, learning a little bit about the fills and combining objects [[part 1](http://gamasutra.com/blogs/ChrisHildenbrand/20111015/8669/2D_Game_Art_For_Programmers__Part_1_updated.php)], the playing around with gradients to set a scene [[part 2](http://gamasutra.com/blogs/ChrisHildenbrand/20111019/8692/2D_Game_Art_For_Programmers__Part_2.php)] and the creation of a game character [[part 3]](http://gamasutra.com/blogs/ChrisHildenbrand/20111027/8713/2D_Game_Art_For_Programmers__Part_3.php) I was going to post the basic animation tutorial next but got a little sidetracked and thought I share this one with you.


Creating a fluffy bird

I just played around with more circles and a different approach to the eyes from the first tutorial... as well as using the bezier curves and straight line tool for some simple shapes.


![](../../assets/b3895b62b93d469a.jpg)



Variation is the key. You can use the elements to form all sorts of critters.
