# 2D Game Art for Programmers - Apache-style helicopter modifications

I got some requests to show how to modify the basic shape of the Apache-style helicopter from the last post to make variations.

![Game Developer Game Developer logo in a gray background | Game Developer](../../assets/de0d06fe69cb2dbe.png)

In the last post I mentioned that it's fairly easy to modify the basics and create variations once you have the core shape down.

[[http://www.gamasutra.com/blogs/ChrisHildenbrand/20120917/177819/2D_Game_Art_for_Programmers__Apachestyle_helicopter.php](http://www.gamasutra.com/blogs/ChrisHildenbrand/20120917/177819/2D_Game_Art_for_Programmers__Apachestyle_helicopter.php) ]
