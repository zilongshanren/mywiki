July 31, 2012

![Game Developer Game Developer logo in a gray background | Game Developer](../../assets/de0d06fe69cb2dbe.png)

Newsbrief: Environmental modeling software developer Interactive Data Visualization has released a new version of SpeedTree, which now features tools for computing wind and support for deferred rendering. [SpeedTree](http://www.speedtree.com/) enables developers to include real-time trees and plants with level of detail transitions in their games. The foliage middleware also offers various lighting, physics, and wind effects. Available for evaluation and licensing starting today, SpeedTree for Games 6.2 now has deferred rendering and multiple render target support in the Compiler app, its shader system, and its software development kit. Other additions include a wind wizard that automatically calculates wind parameters with minimal guidance from users, pre-texture color balance controls that promise faster iterations in Compiler, and more.
