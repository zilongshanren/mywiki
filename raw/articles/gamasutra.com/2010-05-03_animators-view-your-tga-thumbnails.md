If you are a 3D animator or modeler you probably use some package like 3D Studio, Maya, or SoftImage. If you haven't noticed, about 80 - 90% of the texture maps that come with these programs and add on supplemental texture map CDs and DVDs are in Targa or TGA. This is primarily because these files hold [Alpha Channel](http://en.wikipedia.org/wiki/Alpha_channel) information as well as a lossless format. Ironically however :( Windows file explorer does not display thumbnails for TGA. As a matter of fact, I don't even think you can open TGAs in the image viewer.

So if you use are in the middle of 3D modeling and want to find a specific texture you have to preview the file in the little window of the open texture map window in the render software. What is worse is if you have the textures on another computer near by and you just want to glance through them. Well you can't! :( Or can you :)

I found a Windows file explorer plug-in called Thunbplug_TGA. When you load this up on your Windows box it allows you to see TGA files like all the other image formats. I can't even tell you how much times this little plug-in saves me. Anyhow, here is a link where you can download it.[TGA Thumbnail Plug-in for Windows](http://games.greggman.com/game/tga_thumbnails_for_windows/)
