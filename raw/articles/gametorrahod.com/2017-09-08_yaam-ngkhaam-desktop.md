Desktop ที่ว่า หมายถึงโต๊ะทำงานจริงๆ ซึ่งจริงๆแล้วโต๊ะที่ดู “productive” นั้นหลายๆคนอาจจะ get ว่ามันหน้าตาเป็นไง เห็นได้บ่อยตามพวกภาพโฆษณารับสมัครงาน หรือภาพขายของ

แต่มาดูโต๊ะตัวเองทำไมสภาพต่างจากพวกนั้นอะไรแบบนี้!

หลายๆคนคงเหมือนมผมคือ ก็อยากได้โต๊ะที่มันดูเทพๆ แต่นอกจากจะขี้เกียจแล้วยังไม่รู้จะแก้ตรงไหนดี วันนี้ผมจะพามา debug โต๊ะทำงานกัน

## แก้ปัญหา

### ได้ของใหม่แล้ววางไว้บนโต๊ะ

เช่น ไป conference มาแล้วได้ของชำร่วย ไปคีบตุ๊กตามาทั้งๆที่ไม่อยากได้ หรือไปงานโดมาแล้วซื้อของจนลืมว่าจะเอามาไว้ไหน สุดท้ายมันก็อยู่อย่างนั้นมาเกิน 3 เดือนจนเกินเยียวยา เราควรจะให้ desktop ทำหน้าที่ 2 อย่างคือเอาของที่ใช้ประจำไว้ กับเป็นอาหารตาดีกว่าครับอย่าให้เละเหมือน desktop windows ของคอมลุงอานนท์

### มีของที่เบื่อโดยไม่รู้ตัว

ถ้าเป็นอันไหนที่เราชอบเราก็ควรเอาไว้ในสายตาแหละครับ แต่ต้องเข้าใจว่าทุกอย่างไม่ได้ timeless ไปหมด เรามาลองคิดดูดีๆกว่าแต่ละอย่างที่อยู่บนโต๊ะของเรา ตอนนี้เราคิดอย่างไรกับมัน

- อยากเห็นทุกวัน โอเคอันนี้ก็เอาไว้ดีแล้ว
- เริ่มเบื่อ อันนี้จะยาก เพราะทุกอย่างบนโต๊ะเราเป็นของที่เราเคยชอบทั้งนั้น จนไม่กล้าแม้แต่จะคิดว่าเราไม่ได้ชอบแล้ว จริงๆคือไม่ใช่ไม่ได้ชอบ แต่อาจจะถึงเวลาที่เค้าต้องพักแล้ว ดังนั้นเราเอาไปเก็บไว้ในที่ๆเค้าจะไม่บุบสลายได้ไปนานๆดีกว่าครับ
- ไม่ค่อยชอบตั้งแต่แรกแล้ว แต่ตอนนั้นคิดจะลองวางบนโต๊ะไปซักพัก อันนี้เราควรจะทำสิ่งที่น่ากลัวมากก็คือ
**ทิ้งไป**ครับซึ่งถ้าเป็นคนแบบผมที่ไม่ค่อยกล้าทิ้งอะไรอาจจะยาก

ข้อสุดท้ายผมเคยได้หุ่นกระป๋อง Android มาจากงาน conference จริงๆผมก็ไม่ได้อวย Android มากแต่เพราะมันหาไม่ได้ตามปกติก็เลยวางไว้แบบนั้น ตอนนี้ตัดใจทิ้งไปแล้วเพราะที่เก็บดีๆก็ไม่มี

กับมีแผ่นใสอีกอันที่ได้แถมมาจากนิยาย เข้าใจว่าเป็นที่คั่นหนังสือแต่ตอนนั้นอยากเอามาวางไว้ดูเล่น (จริงๆอวยตัวละครอีกตัวนึงแต่พอดีมันได้แผ่นใสตัวนี้) ตอนนี้จอคอมที่เคยเป็นที่เสียบโชว์หายไปแล้ว ก็เลยคิดว่าถึงเวลาที่มันจะกลับไปเป็นที่คั่นหนังสือแล้วครับ ไม่ได้ทิ้ง

![](../../assets/810a6aae5b7b80b2.jpeg)

### เอาของมาใช้ แล้วลืมไปว่าอะไรไม่ได้ใช้บ่อย

ตัวการสำคัญคือ external harddisk ส่วนกรณีของผมคือ mac mini ที่เคยเอามาเปิดเซิฟเล่นๆกับมีจอวางอีกอันที่กะจะเอามาไว้เป็นจอเสริม แต่ลองใช้แล้วไปๆมาๆทำงานช้ากว่าจอโน๊ตบุคจอเดียวอีก แล้วก็จอ mac mini มาค้นพบว่าใช้ screen sharing คุมจาก macbook ได้เลยกลายเป็นไม่ได้ใช้

ทั้งๆที่รู้ว่าไม่ได้ใช้เกิน 2 เดือนแล้วแต่มันก็อยู่อย่างนั้นเรื่อยมา ก็พยายามเอามันออกบ้างครับ (mac mini นี่โชคดีที่มันค่อนข้าง desk friendly ถึงใช้ไม่ได้แต่กลายเป็นที่วางของเฉยๆก็ยังดู ok)

## เทคนิคจัดโต๊ะ

### หลักพื้นฐาน

ก็คือตาอยู่ระดับขอบจอบนแล้วก็แขน 90 องศาแล้วโดนคีย์บอร์ดพอดี ถ้าเป็นไปได้

### ทำให้ว่างที่สุด

อันนี้ง่ายคือเอาของออกไปเท่าที่จะทำได้ แล้วจัดที่เหลือให้อยู่ข้างๆ คอมอยู่ตรงกลาง ถ้าว่างสุดๆก็จะบรรยากาศเหมือนคอม coworking space หรือคอมในห้องสมุด

![](../../assets/432fe1038766a4ab.jpeg)

### รก for aesthetic

บางคนโต๊ะว่างไม่ชอบ ต้องมีอาหารตาซักหน่อย อันนี้ได้ไอเดียมาจากพวกภาพโฆษณาของบริษัทขายของทำเพลง นี่คือตัวอย่างของภาพที่เห็นแล้วรู้สึก “ฮึ้ย!”

![](../../assets/dc6690f44cf16bc5.png)

![](../../assets/6ba4afeec0ceef6e.png)

![](../../assets/af4f68c6777a074d.jpeg)

จะเห็นว่ามีของที่ไม่น่าได้ใช้บ่อยแต่ก็วางไว้งั้นๆแหละ ก็เลยได้ไอเดียว่าอะไรที่วางแล้วสวยด้วย แทนที่จะไปวางในที่เก็บของมาวางบน desktop ได้ ประหยัดที่เก็บของด้วย (สำหรับคนไม่ชอบโต๊ะว่างๆ) ใส่ต้นไม้ก็น่าจะได้แต่ผมไม่ชอบให้มีดินกับน้ำบนโต๊ะเท่าไหร่

![](../../assets/315710f7598086c5.jpeg)

อันนี้ที่มุมโต๊ะตอนนี้ ไอ้ขวดหมึกนั่นมันไม่ได้เกี่ยวอะไรกับ tablet เลย วางทับไว้ทำให้ไม่พร้อมใช้งานอีกต่างหาก แถมตอนนี้ไม่ได้ถึงขั้นตอนที่ต้องวาดภาพด้วย แต่พอดีสีดำมันเข้ากันดีก็เลยมาวางไว้บนโต๊ะงั้นๆแหละ

### LR flip

ถ้าจนปัญญาไม่มีอะไรเอาออกได้จริงๆ แค่ย้ายของไปมาหรือแค่สลับซ้ายขวาก็ค่อนข้างรู้สึกสดชื่นขึ้นได้

### เปลี่ยน Desktop (คอม)

ถ้าเป็นคนง่ายๆอะไรก็ได้ บางทีเผลอใช้ desktop เดิมมาเป็นปีก็มี ถ้าหัดเปลี่ยนซะบ้างจริงๆก็มีผลเหมือนกัน ถ้า Windows เปลี่ยนสี title bar ได้ ถ้า macOS เปลี่ยนสีแถบข้างบนเป็นสีขาวหรือดำได้ด้วย

### เรียงให้มีเส้นขนานหรือสมมาตร

ภาพก่อนจัดจะเห็นว่ามันดูกากที่ว่าปลั้กพ่วงสีเขียวมันวางเบี้ยวแล้วไม่ขนานกับขอบโต๊ะ ถ้าทำให้ขนานได้จะให้ความรู้สึกเรียบร้อย หรือทำเป็นเส้นซูมเข้าตรงกลางก็ได้นึกภาพคนที่มี layout 3 จอแล้วสองจอข้างๆเฉียงเข้าตรงกลางเป็น perspective อันนี้ถึงไม่ขนานแต่สมมาตรแล้วก็น่าจะดูดี

### ใช้ vertical space

อันไหนสามารถวางทับกันขึ้นไปข้างบนได้จะช่วยสร้างมิติให้โต๊ะไม่แบนได้ครับ นึกสภาพโต๊ะที่มีแต่กระดาษ A4 วางเกลื่อนจนเต็ม แต่เต็มแค่ 2 มิติ เทียบกับเอากระดาษมากองเป็นตั้งอันไหนจะน่าหงุดหงิดน้อยกว่ากัน

![](../../assets/d3e7c929981fd8b8.jpeg)

อันนี้ mac mini ที่วางบนโต๊ะก็ดูสวยอยู่แล้ว พอดีข้างบนเรียบด้วยทำให้สามารถซ้อนกองทัพตุ๊กตาขึ้นไปข้างบนได้อีก ถ้าเป็นบ้อง mac pro คงทำไม่ได้

คงมีเทคนิคอื่นๆที่รอให้ค้นหากับโต๊ะของเราอีก คงต้องศึกษากันต่อไปครับ!
