Review (ข้อเสีย) Slack… และคุยกันเรื่องบทเรียน User Interface ด้วย

หลังจากที่พวกทีมผมลองใช้ไอ้ Slack ทึ่ใครๆก็ว่าดีนี่มาเป็นเวลาประมาณปีกว่าตอนที่อยู่ญี่ปุ่น แทนที่กรุ๊ป FB ก็ได้รู้ว่ามันมีข้อเสียพอสมควรที่จะมาเล่าให้ฟัง (ข้อดีเว็บมันน่าจะโฆษณาเยอะอยู่แล้ว ไปดูเอาเองก็แล้วกัน)

- ไอ้แบ่งเป็นห้องๆก็ดีอยู่หรอก แต่ noti มันไม่ชัด ห้องไหนมีอะไรใหม่ก็บอกแค่ตัวหนาขาวๆ
- ไม่มี Seen เหมือนจะดี แต่พอทีมผมมันเงียบกันก็เลยยิ่งกังวลว่ายังไม่เห็นหรือเข้าใจแล้ว สุดท้ายก็ต้องใช้ FB Messenger ไปทวงอยู่ดีว่าเห็นใน Slack รึยังเพราะวันๆเล่นแต่โซเชียลปกติกัน
- ในห้องมันมีลักษณะเป็น chat room แต่ตอนใช้ FB secret group พอแบ่งเป็น post ได้รู้สึกว่ามัน engaging กว่าเยอะ ของ Slack มันดู..เรื่อยๆเอื่อยเฉื่อย ไม่มี topic ในการคุยกันเลย แถมไถหายากมาก ของ FB เหมือนกับว่าลูกทีมทุกคนกำลังมอง “กระดาน” เดียวกันอยู่ระหว่างเวลาคุยอะไรกันไปด้วย (ก็คือหัว post หรือภาพหัว post) ทำให้รู้สึก in the zone
- ใน “ห้อง” ของ Slack มันเหมือนจะเป็นหน่วยที่ทดแทน “post” ของ FB ไม่ได้เพราะมันใหญ่กว่า แต่ขณะเดียวกัน ในห้องก็ไม่มีหน่วยที่เล็กกว่าให้ใช้ เหมือนข้างในเป็นทะเล chat ขาวๆเรียงเต็มเลย ทั้งๆที่มีบางบรรทัดสองบรรทัดที่สำคัญมากซ่อนในนั้น เช่นบอกว่า เวอร์ชั่นใหม่เพิ่มอะไรดี ถ้าเป็น FB อันนี้จะควรงอกเป็น post ใหม่ แต่ใน Slack ถ้าพิมพ์ไว้มันจะจมหายเวลาคุยกันไปซักระยะนึง อีกทางคืออาจทำให้ต้องตั้งห้องใหม่ ซึ่งตรงนี้ผมชอบของ FB มากกว่าเพราะ post ใหม่มันยังถือว่าต่อกับ post ที่แล้วเวลาไถลงมา chronologically (โดยไม่ expand ที่คุยกันไว้ใน post) แต่พองอกห้องใหม่ใน Slack แล้วมันเหมือนคนละโลกกันเลย เวลาเปลี่ยนไปมาเหมือนวาร์ปไปมา ทั้งๆที่จริงๆควรจะเรียงต่อจาก “ห้องที่แล้ว” (ห้องใน slack เรียงตามตัวอักษรไม่ใช่ตามเวลาหรือตามจัดได้ ฯลฯ อย่างเดียวที่เรียงตามเวลาคือ chat message ในห้อง)
- อัพภาพทีถามหา metadata เยอะเกิน สุดท้ายก็ไม่ได้ใส่อะไรแค่อยากโชว์ภาพให้กันดู
- ระบบ pin ที่เหมือนจะเอามาไว้ใช้ตั้งหัวข้อก็ไม่สู้ post-based ของ FB อยู่ดี pin แล้วก็เล็กจนมองผ่านๆแล้วมองไม่เห็น แถมถ้าใครไม่เปิดอีแถบข้างๆไว้ก็ไม่มีทางเห็น pin
- ใน FB Post นึงมันมีสรุปจำนวนที่คุยกันไว้ด้วยกรณีที่คุยยาวๆ แต่ของ Slack มันรู้สึกได้ว่า “ไหลหายไป”
- ลงวิดิโอแล้วดูในนั้นไม่ได้ กลายเป็นต้องโหลดลงเครื่องเพื่อดู ลำบากมาก ของ FB ตอนนี้แม้แต่คอมเมนต์ยังวิดิโอได้
- ไลค์แล้วไม่สะใจ ด้วยความที่มันหน้าตาเหมือน chat มันรู้สึกว่าแต่ละข้อความ มันถี่เกินจนไม่รู้จะกดไลค์อันไหน ไปๆมาๆก็ไม่มีใครกดหลังจากผ่านไป 1 เดือน คือเวลาคุยมันเหมือนคุยแชทจริงๆ แล้วก็การแสดงผลของไลค์ดูไม่ satisfying เท่าของ FB แล้วของ FB ยังสามารถไลค์ post หลักได้ด้วย ตรงนี้ผมเห็นว่าสำคัญที่สุดเพราะแสดงถึงความเห็นด้วยใน concept ใหญ่ๆที่เอามาเสนอทีม ใน Slack กดไลค์ข้อความ chat มันดูยิบย่อยเกินจนไม่ค่อยมีความสำคัญ (เพราะเดี๋ยวก็ไหลหายไปแล้ว) ถ้าจะกดไลค์ห้องแชทก็ดูกว้างเกิน (ชอบอะไร?) ปัจจุบันเลยไม่ค่อยเห็นแอพแชทปกติไหนสามารถไลค์ข้อความได้ เพราะพิมพ์ตอบไปว่าชอบเลยน่าจะดีกว่า
- ทีมแมร่งไม่เช็ค Slack กัน พอใช้ FB ปุ้บตอบเร็วไว

ทั้งหมดเหมือนจะสรุปได้ว่า Slack มันทำหน้าตาเหมือน chat แล้วผลตามมาหลายๆอย่างรู้สึกมันไม่เหมาะกับการทำงานเท่าแบบ post ครับ ถ้าคุยกันเรื่องหน่วยของสารที่จะสื่อ เหมือนว่า “post” ของ FB นี่อยู่ตรงกลางระหว่าง chat กับ forum

ซึ่งถ้าลองนึกว่าไป dev เกมโดยเช่า bulletin board มา หน่วย forum มันจะดู overkill ไปตรงที่ต้องเซาะเข้าไปดูข้างในและการคอมเม้นต์แต่ละทีมันก็จะแยกเป็น reply ที่ใหญ่เกินไป ขณะเดียวกัน chat ก็เป็น linear เกินไป พอคิดแบบนี้แล้วรู้สึกว่าหน่วย post ของ FB นี่เขาคิดมาเจ๋งดีเหมือนกันครับ แบ่งหัวข้อได้ละเอียดพอดี + reply เล็กๆพอเหมาะ สามารถสรุปขึ้น Feed ได้และ scroll through มองผ่านๆได้ดีกว่าทั้ง forum ทั้ง chat เพราะมันนำเสนอในรูปแบบ “Cards”

ส่วนตัวคิดว่าแพ้ FB Group เยอะเกินไป (แถมของ FB มันฟรีด้วยแน่ะ) ก็ดีที่ได้ลองกับตัวถึงได้รู้ไม่ใช่เชื่อคนอื่นตามๆมาอย่างเดียว จะได้ลองหาตัวเลือกอื่นที่เหมาะกับทีมมากกว่านี้ (ปล. โพสต์ต่อไปจะมาแนะนำ “Workplace” จาก FB… ซึ่งเหมือนจะทำมาตอบปัญหาทั้งหมด 10 ข้อที่พิมพ์ไปเลย แต่อันนั้นไม่มี tier free ให้ใช้เหมือน Slack โดยนับ 3$ ต่อคนครับ ว่าจะลองใช้ฟรี 3 เดือนที่มันจะให้ดู)
