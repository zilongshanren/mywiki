แล้วเว็บนี้มาพูดเรื่องกินคลีนทำไม ตอนแรกก็เฉยๆนะ ก็ไม่ได้เล่นกล้ามไม่ได้รักสุขภาพขนาดนั้น แต่คิดไปคิดมาถึงบรรลุ จะบอกให้ว่ามัน**เกี่ยวกับ game dev** อย่างมากเลยล่ะ คือ!

- อาหารคลีนต้องทำเอง เพราะลงไปซื้อข้างล่างคงควบคุมแม่ค้าให้คลีนไม่ได้ ซึ่งก็เหมาะกับคนทำเกมพอดีอยู่แต่ในห้องทั้งวันแมร่งเลย
- อาหารคลีนเหมาะจะตุนและทำไว้เยอะๆ จำพวกอกไก่ย่าง บรอคโคลี่ต้ม พวกนี้ฟรีซไว้เวฟได้ทั้งหมด เหมาะจะเอามาตุนเต็มตู้แล้วจะได้กินได้เลยไม่เสีย flow ในการ debug โปรแกรม เพราะถ้าไม่ตุนแล้วเปลี่ยนไปเรื่อยๆทุกวัน มันจะแพง แล้วคนทำเกมมีตังซะที่ไหน
- โปรแกรมเมอร์ทรหดอย่างเราๆมักจะกินเพื่ออิ่มเพื่อรีบมาทำงานต่ออยู่แล้วไม่ค่อยจะได้สุนทรีย์กับรสอาหารเท่าไหร่ ดังนั้นถ้ามากินคลีนที่มีแต่ของจืดๆ วันๆก็ต้องกินแต่ซ้ำๆเพราะถ้าเปลี่ยนจากอกไก่เป็นอย่างอื่นที่คลีนแมร่งก็แพงกว่าซิงเกอร์เบอร์เกอร์อีก ก็ไม่มีปัญหา! ทำให้ทั้งตู้เย็นมีแต่อกไก่กับผักซักชนิดนึงไปเลยก็อยู่ได้ ตอนอยู่ญี่ปุ่น ผมกินข้าวผัดเหมือนกันเด๊ะๆที่ทำเองในห้องติดต่อกันมา 10 วันก็ทำมาแล้วเพราะมันอร่อยง่ายร้อนแล้วก็อิ่มไว เรื่องเบื่อเราไม่แคร์
- โปรแกรมเมอร์นั่งขยับแต่นิ้วไม่ได้ใช้พลังงานมากอยู่แล้วกินคลีนคงไม่ทรมานมาก
- อาหารคลีนมักจะเป็นจำพวกย่าง ที่ต้องใช้เวลานาน แต่มัน unattended คือปล่อยทิ้งไว้ได้ คนปกติทั่วไปที่ต้องออกไปทำงานอาจจะทำอะไรลำบากเพราะยังไงก็ต้องกลับมาดู แต่! ถ้าเราเป็นโปรแกรมเมอร์อยู่ห้องอยู่แล้วก็ไปทำเกมเพลินๆแล้วค่อยมาเช็คก็ได้ ดีไม่ดี ดีกว่าอาหารที่ต้อง full attention แบบไข่เจียวอะไรงี้อีก
- และด้วยการที่ต้องใช้เวลาย่างทิ้งไว้ทำให้สนุกและลุ้นกับการรอผลที่จะออกมา ทำให้มีกำลังใจเขียนโปรแกรมเพราะมี checkpoint อยู่ว่าเมื่อไหร่ที่ย่างจะเสร็จ เครื่องปรุงที่ปรับไปจะให้ผลยังไงนะ
- เหมือนที่เราอยู่ๆก็เลือก hard mode เพื่อทรมานตัวเองเล่น พอเห็นการกินแบบใหม่ๆก็รู้สึกท้าทายคล้ายๆกัน ว่าโลกใหม่ที่รออยู่จะเป็นไง อกไก่ ส่วนที่ราคาถูกแล้วได้เยอะ ทำไงจะอร่อย ผักต้มยังไงจะดีที่สุด ยังมีเทคนิคที่ทั้งชีวิตไม่เคยเหยียบมาโซนนี้อยู่อีกเยอะ

อะไรๆก็เคมีตรงกับ game programmer ขนาดนี้ แล้วจะรอช้าอยู่ไย!

สำหรับคนที่ไม่รู้ว่าคือไรไอเดียหลักก็คือกินอาหารที่ processed น้อย พวก เบอร์เกอร์ ฮอทดอก แฮม อาหารกระป๋องงี้ ผ่านมาหลายขั้น ซอสมะเขือเทศงี้ ก็ผ่านมาหลายขั้นแถมมีน้ำเชื่อมในนั้นเพียบ ก็ต้องเปลี่ยนมาบดมะเขือเทศเองหรือซื้อแบบกระป๋อง ฯลฯ จริงอยู่ที่กินๆไปสุดท้ายก็กลายเป็นแค่สารเคมีเดียวกันไม่ว่าจะมาจากแหล่งไหน แต่กินตามปกติคงมีสารอื่นที่ไม่ใช่คาร์โบไฮเดรตโปรตีนไขมันที่อยากได้อยู่ด้วยไง แล้วอันที่อยากได้มักจะเกินเช่นเกลือ จริงๆคลีนมันก็ฟังดูเป็น buzz word เว่อๆคำนึงเลยแหละ แต่ลองดูก็น่าจะสนุกดี (เป็นเกมเมอร์ เอาสนุกก็พอใจแล้วน่ะ)

เอาเป็นว่าตอนนี้ลองกินคลีนๆดูว่าจะไปได้ซักแค่ไหน จะพยายามปรับสูตรไก่ย่างก่อนแล้วค่อยขยายไปทางอื่นดู ภาพคือไก่แรก จืดไปหน่อยเดี๋ยวปรับสูตรเรื่อยๆ
