มีเรื่องนึงคือเรื่องการพัฒนาความสามารถตัวเอง ที่มีความเห็นที่ได้ยินกันส่วนใหญ่ไปในทางที่ว่า ถ้าทำงานออฟฟิศอาจจะพัฒนาขีดความสามารถได้ช้ากว่า Freelance หรือถ้าออฟฟิศเทียบกัน บ. เอกชนก็จะมีโอกาสเก่งขึ้นมากกว่า บ. ของรัฐ ฯลฯ

เรื่องขีดความสามารถส่วนตัวก็อย่างนึงที่เราจะไม่พูดถึงในนี้ แต่ตอนนี้ผมเพิ่งรู้สึกถึงสิ่งที่ทำให้ freelance เก่งช้ากว่าได้ ที่ไม่เคยคิดมาก่อน

** นั่นคือ tools upgrade! **

มันโยงกับหลายๆอย่างครับ แต่หลักๆคือพอเราไม่มีเงินเดือนมั่นคงนี่แหละ มันทำให้เราไม่สามารถ upgrade ของตามใจชอบได้!! …ในระหว่างช่วงเวลา dev เกมแรกๆ

นึกสภาพเล่น RO แล้วใช้ของ Novice จนเลเวล 30 แล้วค่อยเปลี่ยนทีเดียวอะไรงี้ครับ เทียบกับถ้าเปลี่ยนก่อนหน้านี้ซักหน่อย เวลาใช้งานมันก็คืนทุนอย่างรวดเร็วเพราะ effect มันก็ทับถมกันตามเวลามากขึ้น แต่นั่นหมายความว่าต้องมีเงิน แล้วลองคิดว่าเกมจะไม่ให้เงินจนกว่าจะเลเวลถึง 30 …

ตอนนี้ผมรู้สึก stuck in time มาก คือ iPad ก็เป็น iPad 3 ที่ตอนเริ่มทำเกมพอเป็น benchmark ได้แต่ตอนนี้ก็ไม่แล้ว มือถือ Nexus 5 ที่ซื้อมาจากญี่ปุ่นตอนนั้นเร็วมากตอนนี้ก็ลอยแพแล้ว เปิดไม่ติดด้วยแถมซื้อใหม่ไม่ได้จนต้องยืมเพื่อนใช้ แล้วก็คอมที่ซื้อ MBP มาก็ดีนะ แต่สิ่งที่อยากได้ใน desktop ก็คือจะได้เรนเดอร์เร็วๆได้ iterate เร็วๆรัวๆใน Blender ได้ไม่ใช่เข้า Facebook ได้ทุกครั้งที่จะดูเฟรมนึง แล้วก็… เล่น Overwatch ให้ได้มากกว่า 20–30 FPS ได้ 555

ทำ full freelance แบบนี้มีอิสระในเวลาครับ แต่ลืมนึกไปว่าเราจะอยู่กับ equipment เซ็ตนี้ไปตลอดจนเกมเสร็จแล้วมีทางได้เงินจริงๆขึ้นมา ถ้าไม่หาทางหาเงินระหว่างทางด้วย

ซึ่งตาม Moore’s Law (เดี๋ยวนี้อาจจะไม่ค่อยจริงแล้ว?) ถ้าทำเกม 2–3 ปีป่านนี้อาจจะวิ่งไปไกลแล้ว กลายเป็นเวลาที่ได้มาโดนหักล้างจากการใช้ tools เก่าหมดเลย

คิดดูสมมติถ้าผมทำงานปกติแล้วได้เงินเดือน 25k นี่ น่าจะเลือกอัพเกรดได้อย่างนึงในระยะเวลา 3 เดือนเลย (ถ้าตัดสินใจแล้วว่าจะเลือก upgrade เน้นๆแล้วพักเรื่องเงินเก็บไว้ก่อน) แล้วถ้ามีของชิ้นนั้นอยู่ ใครจะไปรู้ป่านนี้เกมผมอาจจะเสร็จไปแล้ว เสร็จก่อนตัดสินใจไม่เข้างานแล้วเอาเวลาเข้าแลกแบบนี้ก็ได้! สมมติเกมเสร็จแล้วผมได้เงิน 40k แล้วไง เวลาก็เสียไปแล้ว คนมีเครื่องมือดีที่มีเงินหมุนมาอัพเกรดก็ทำเกมเสร็จแล้วได้ 40k เหมือนกันแต่อาจจะเสร็จไวกว่าผมที่อัพของไม่ได้

แล้วก็.. tools ใหม่ทำให้เกิด skill ครับ ป่านนี้ถ้าผมมี iPad Pro กับ desktop ที่มีการ์ดจอซักหน่อย ผมอาจจะเก่ง Blender กว่านี้ แล้วก็อาจจะใช้ Procreate/Affinity Designer ทำงานเป็นไปแล้วก็ได้นะ นี่ยังไงก็ยังแบบนั้น บัค Oreo ก็ต้องมาเดาเอาว่าน่าจะไม่มีหรอก

สรุปคือเป็นไปได้ที่ เงินเดือน -> upgrade tools -> ประหยัดเวลา -> เกิดการเรียนรู้ -> Level up

ดังนั้นใครไม่ใช่ pure freelance แต่ทำเกมเป็นเวลานอก ก็พยายาม exploit ข้อได้เปรียบตรงนี้ผมว่าดีไม่ดีชนะ freelance ได้ เหมือนอาชีพที่ใช้ item เข้าสู้

ถ้าใครกำลังตัดสินใจว่าจะเอาเกมล้วนๆ เพราะกลัวทำอย่างอื่นไปด้วยแล้วจะเต็มที่ไม่ได้ ก็อย่าลืมว่าถึงเต็มที่ไม่ได้แต่อาจจะใช้เงินมาทำอะไรซักอย่าง ให้เต็มที่ไม่ได้ดียิ่งกว่าเต็มที่อีก งงมั้ย 555 เพราะเวลาไม่ใช่ทุกอย่างครับ จริงๆผมอาจจะคิดผิดก็ได้ที่ไม่เอางานปกติไปด้วย
