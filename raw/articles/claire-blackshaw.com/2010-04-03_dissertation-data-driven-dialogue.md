Aim

To create a data-driven system for use in the games industry that will generate complete social interactions using seeded scenarios which expands based on player interactions and arbitrary input. This is an alternative to dialogue trees.

Task List

- Create Scenario Reference
- Draft scenario and characters
- Draft topics of conversation
- Compile Final Scenario reference

- Create a traditional scenario using dialogue tree.
- Create Simple Example in Adventure Game Studio
- Implement Scenario Reference in Adventure Game Studio

- Research Morrowind dialogue, and modding community
- Create some Morrowind Dialogue
- Evaluate possibility of implementing

- Model a new data-driven system
- Implement Scenario Reference using new system

- Compare and Evaluate different methods
- Compile Final Report
