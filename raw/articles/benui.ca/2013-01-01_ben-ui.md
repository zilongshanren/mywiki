# ben ui

#### Unreal Engine UI Programmer


## Summary

- Over 10 years' industry experience with
**Unreal Engine** and C++, with specialization in UI programming. - Experience in indie, AA and AAA teams.
- MEng Computer Science (1st) at the University of Southampton, UK.

## Employment History

- I currently work at Next Level Games as a Senior UI Programmer.

- I worked at
**Epic Games** as a **UI Programmer** from May 2023 to January 2025. I mostly worked on LEGO Fortnite [Odyssey](https://kids.lego.com/campaigns/fortnite) (survival and crafting) and [Brick Life](https://www.fortnite.com/news/lego-fortnite-brick-life-build-your-life-in-the-big-city) (social hangout). - Implemented full-screen widgets like the Village Management screen. Wrote code that gathered the required data from various C++ systems and provided them to technical designers.
- Adding
**data replication** to server-only systems to ensure data is available in client-side UI features. - Ensured that code worked with the gigantic existing Fortnite codebase.
- Improved workflow for team members (and the community at large) by adding improvements to Unreal Editor.
- Worked extensively with
**Game Feature Plugins**, separating functionality for the live release schedule. - Used Unreal's
**MVVM system** to implement "apps" on the player's phone.

- I was Lead Programmer on an unannounced project at
[Brace Yourself Games](http://www.braceyourselfgames.com/). It was cancelled during the studio layoffs in May 2023. - Worked on
**implementing 3rd-person action/strategy** prototypes using Unreal Engine 5, using Marketplace plugins and [DearImGui](https://github.com/ocornut/imgui). - Gained experience with networking, character animation, collision detection, character navigation.
- Managed another programmer; wrote task specifications, reviewed code.
- Creating a combat system that integrated real-time complex collisions with rule-based triggers.

- I worked on
**city-builder** [Industries of Titan](http://www.industriesoftitan.com) as the **UI programmer and designer**, in a core team of 5~6. - Implemented game UI in
**Unreal Engine 4** using C++ (UMG and Slate) and Blueprints. - Implemented
**centralized asset styling** system and enhanced standard Unreal widgets. - Created a custom
[rich text markup system](https://github.com/BraceYourselfGames/UE-BYGRichText) that accepted Markdown-like formatting. The system supported inline formatting, inline icons and tooltips. - Created a custom
[fan-translation-friendly localization system](https://github.com/BraceYourselfGames/UE-BYGLocalization). The system allowed fans to drop in CSV file translations, and gracefully fell back to English for untranslated strings. - Created
**tools to improve the workflow** of designers, artists and writers, allowing them to seamlessly define data in Google Sheets and see their changes in-game. - Created
**in-game bug reporter** and to accept player feedback, screenshot and saves. - Created
**UI art and designed the user experience** in collaboration with the art director, with the aim to let players understand the inner workings of their city without being overwhelmed.

- I worked on action-RPG
[Vampyr](http://www.vampyr-game.com) as the **main UI programmer** in a team of ~100. - Created menus including:
**inventory management**, character progression, map, dialogue, crafting. - Implemented a "Destiny-style" free-cursor navigation system with detailed, animated tooltips.
- Worked extensively using
**Blueprints**, later improved performance by moving intensive parts to C++. - Worked with artists on initial concepts to ensure
**consistency, user-friendliness, localization** of interfaces. - Managed team of 3 UI programmers, allocating tasks, reviewed code and giving technical guidance.
- Created
**custom materials** to support UI artists. - Created a
**smart subtitles system** following [best practices from TV and film](https://benui.ca/ux/make-game-subtitles-better/).

- I worked on Monster Boy and the Cursed Kingdom, a 2D platformer-RPG as part of a small ~5 person team. The game was made using a custom C++ engine and released for release on PC and consoles.
- Implemented
**gameplay systems** including enemy behaviors, player abilities (attacking, swinging, swimming etc.), all menus including the equipment menu. - I added
**Lua scripting** to the existing engine to allow designers to create **triggers and quests**. - I worked on the UI, creating
**the equipment menus** and **shops**.

- I worked on
**IA/VT -COLORFUL-**, a rhythm game written in **C# and Unity** for PSVita as part of a small 5-person team. - I created the
**music video director system** that showed the **character**, **animations** and **special effects** behind the rhythm game. I created a workflow that allowed artists to set up **timelines of camera changes, full-screen effects, character animations and special effects.** - As part of the music video system, I wrote
**CG shaders** to **implement the concepts created by artists**. - The
**main character** had a large number of **outfits and animations**, I created the system to split them up, **load them quickly and asynchronously** with the Vita's limited resources. - I also created the majority of the
**main menu system** and **skinnable in-game UI**.
