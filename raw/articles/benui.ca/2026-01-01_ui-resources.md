Outside Unreal related tutorials there are a lot of resources that can help you grow as a UI designer.

## General

[We can fix it in UI](http://www.wecanfixitinui.com/)is a Discord server for people in, or hoping to join, the video games industry in a UI-related role.[Game UI Database](https://www.gameuidatabase.com/)has a gazillion UI screenshots from every game imaginable. It's a phenomenal resource.

## Typography

If you're serious about design, it's good to know about typographic terms, theory and some practical guidelines.

[Detail in Typography by Jost Hochuli](https://www.typotheque.com/books/detail_in_typography/)— If I had to recommend a single typography book, it would be this. It's concise but detailed. Covers the basics but doesn't skip more nuanced topics. Has a great mix of theory and practical application.
