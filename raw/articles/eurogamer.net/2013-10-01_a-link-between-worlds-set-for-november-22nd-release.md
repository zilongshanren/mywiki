[A Link Between Worlds](https://www.eurogamer.net/games/legend-zelda-link-between-worlds), the spiritual successor to the SNES classic Link to the Past, has been set for release on November 22nd for the Nintendo 3DS - and its new dungeon system has been explained for the first time.

Unlike in previous Zelda games where dungeon order is largely prescribed, in A Link Between Worlds after a certain point you'll be able to tackle dungeons in any order, using tools and weapons that you can buy or hire from an in-game shop. The shop, staffed by a character called Ravio, was teased earlier this year in a Miiverse post.

A Link Between Worlds is the Zelda series first original outing on the Nintendo 3DS, following the release at launch of an updated [Ocarina of Time](https://www.eurogamer.net/games/the-legend-of-zelda-ocarina-of-time) - though [from early impressions](https://www.eurogamer.net/the-legend-of-zelda-3ds-preview-linked-to-the-past) it looks as if this new Zelda won't be quite as bold as some of its predecessors.
