# About me

You might know me as the guy who does indie PS1 games. :)

![](../../assets/421cf3d560b4588f.jpg)

I’m a professional programmer and an indie game developer in my free time. I’m a solo developer - I do programming, art, music and everything else.

I’ve started programming in 2009 in C++ (and have been using C++ as my “primary” language since then). I’m also procifient at Lua and Go.

## What I use for my work

- Most of my work is done on GNU/Linux Debian.
- My Linux setup is pretty minimalist: I use i3 and “boring”/standard/proven tools mostly.
- I program in Vim.
- I use GDB as the debugger.
- I use Blender for 3D modelling.
- For drawing and texturing, I use GIMP, Krita and Aseprite. I also use Clip Studio Paint for sketching and some art.
- I use REAPER, OpenMPT and Renoise for making music.

### Project MPT (March 2023 - Present)

A mysterious adventure game about a cat. The project is now developed for PS1 from July 2024.

![](../../assets/affc6ad2ab05061d.png)

This is my first 3D game - I’m developing it with my custom engine which does graphics with Vulkan. The engine has PBR and deferred shading implemented, as well as many other things that a proper 3D game engine needs.
