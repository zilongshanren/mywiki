Just got this banger new update for my 3D conversion ReShade effect called [Rendepth](https://rendepth.com/). Code was pushed out to [GitHub](https://github.com/outmode/rendepth-reshade) yesterday, and can be installed directly through the [ReShade installer](https://reshade.me/). The biggest change has been in (mostly) resolving the artifacts around discontinuities in depth (meaning glitches on first-person guns or characters in third-person games). There’s been a few smaller bug fixes and quality tweaks, so overall this latest version, 2.1.0, looks the way I had originally envisioned. Video above talks in more detail about the quality improvements and mitigations to artifacts.

![](../../assets/4c3c8ce682041563.jpg)

Download the update now by [installing via ReShade](https://reshade.me/), then selecting Rendepth (and also install the add-on version for 3D Game Bridge, which is needed on Samsung and Acer “glasses free” 3D displays). On [the official GitHub page](https://github.com/outmode/rendepth-reshade), there are detailed setup and installation steps for new users. 100% free and open-source.
