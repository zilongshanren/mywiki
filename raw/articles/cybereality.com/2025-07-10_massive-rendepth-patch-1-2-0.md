Just got a massive update out for Rendepth, my stereo 3D image viewer and AI 2D-to-3D app. You can download for free at [rendepth.com](https://rendepth.com), source code is also available. Only the Windows and Linux versions are live right now, the MacOS version is an older build, since I need to sort out some signing issues (typical Apple BS). Should be posted later this week. This is also the first build with an RPM package, since I recently switched to Fedora as a daily driver.

Tons of small improvements since the original release. Switched to borderless window (by default), added an RGBD display mode, better handling of automatic 3D image detection (now supports both half and full-width SBS photos), optional tooltips for all the buttons, image metadata display (filename, resolution and disk size), better support for OS display scaling, huge performance improvements, smoother UI animations, and a couple odd bug fixes (including a big memory leak).

Should have probably posted smaller updates every month, however I was sorting out some legal stuff and wanted to get things in order first. Still not 100% complete (related to app signing), though I just pushed the builds up anyway (Windows unsigned, and Linux where it’s not needed) and hopefully I can get this business BS sorted out within the next week or so.
