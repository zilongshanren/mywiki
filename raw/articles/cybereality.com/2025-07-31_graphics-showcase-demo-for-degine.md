Got together a new demo video for Degine, my custom OpenGL 3D game engine, showcasing the current state of the graphics. This 1 minute clip is my submission for the GP-Direct 2025 compilation, with a few dozen other indie game developers and graphics programmers. Stuck a peak at what some other contestants have been working on, and it looks like this year’s gonna be a banger.

![](../../assets/6a3dc5269d1bdd5a.jpg)

Was hoping to release a real-time demo in August, we’ll see how that goes, but I may want to make something with simpler assets for the first downloadable demo, that’s optimized for mobile and web targets. Also planning on getting the website up soon (already designed a while ago) so I can start promoting. Hard to say when things will be done, but realistically I think I can get Degine stable in 2026, and ideally put out an MIT License FOSS release sometime in the next few months, in order to get feedback before the full release. Stay tuned.
