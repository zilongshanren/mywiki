# New GM Shaders Tutorial!

Hey folks!

It's been a little while, but I'm back with a [new shader tutorial](https://gmshaders.com/tutorials/basic_colors/) on basic color effects (such as color inverting, grayscale/saturation, and sepia tone)!

**Collaboration Tutorials**

I recently got my friend, [Bart](https://github.com/bartteunis), on board to help me produce tutorials more efficiently. I found that I love writing the code, but explaining these topics to beginners can be difficult and time-consuming. Bart is a good writer who is better suited to explain from a beginner/intermediate perspective. So for the next few tutorials, we're going to try co-writing (I write code/examples, he writes explanations) and we'll see how it's received!

**Next Tutorial?**

The next tutorial will be covering more advanced color effects. We already have the next several tutorials planned and hopefully, we can begin producing them more quickly now with the extra help!
