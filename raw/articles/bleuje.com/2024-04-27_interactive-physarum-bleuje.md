Interactive real-time simulations with gamepad interaction. It has been used as artistic installation. It’s using the algorithm in the work [36 Points](https://www.sagejenson.com/36points/) from [Sage Jenson](https://sagejenson.com/). See this [ explanation article](https://bleuje.com/physarum-explanation/).

**Demo video**: (remark: video from May 2024, before color improvements)

. It contains the code to try it yourself. Attribution details are given, and the algorithm is explained.**Github repository**
