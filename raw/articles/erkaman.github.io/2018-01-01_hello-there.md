This is the website of **Eric Arnebäck**, a Swedish
developer currently based in Sweden. I am a software developer
specializing in **Real-time Computer Graphics**, mainly using
technologies such as **OpenGL**, **WebGL**, **Unity** and **Direct3D** with
the languages **Javascript**, **C++** and **C#**. I also have skills in Front-end web dev,
using **React.js** and **Javascript**.
I am also skilled in the areas of **Digital Geometry** and **Computer Vision**.

In my spare time, I like to work on side projects related
to computer graphics, study the latest research within
computer graphics, and
write [articles](https://erkaman.github.io/articles.html) for my
website.
