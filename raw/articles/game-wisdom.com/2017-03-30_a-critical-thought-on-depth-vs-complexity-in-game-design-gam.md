Today’s Critical Thought looks at the difference between depth vs. complexity in game design. Just because a game is complex, doesn’t make it deep. There is a lot to talk about in this topic, but we kept things basic for the chat. A good game design should be easy to learn ,difficult to master; not the other way around.
