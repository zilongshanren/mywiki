We wanted to make something special for our most successful game and our players so we added some Christmas happiness to [Vampire Runner](https://blog.gemserk.com/games/vampirerunner):

![Vampire Runner](../../assets/d8d5860881d3a375.png)


The changes for this version were:

- Christmas Theme - Presents, Trees, Christmas Hats, and Snow.
- Musics are disabled the first time you run the game, to avoid a bug between OpenFeint dialog and LibGDX (you can enable the music in the main menu screen).
- For the Android Version - We now support paging on our highscore screen so you can see more scores.
- Created
[Vampire Runners Facebook Page](https://www.facebook.com/pages/Vampire-Runner/260666463994210)and added a button to go there from the Credits Screen.
