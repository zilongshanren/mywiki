Some people told us that our games where hard to find on the blog so we are working on making finding them easier. In order to do that, we first created a new button **Games** to let you find our games easily. It should be on the right sidebar, do you like it?

Also, as we have a lot of games right now, updating the [Games page](https://blog.gemserk.com/games/) manually is quite annoying. To improve that, we created a basic WordPress plug-in named [wp-games-gallery](https://github.com/gemserk/wp-games-gallery) which creates a simple gallery of games based on each game page meta data. So now, each time we create a new game page, the games list should be updated properly.
