Master the flight of the Super Flying Thing traveling through complex paths and dodging multiple obstacles while collecting stars and reaching the target planet alive.

### Features

- Fun and simple game mechanics
- Challenge mode with multiple levels.
- Random mode with random generated levels to keep you playing eternally.
- Practice mode with ship invulnerability to learn how to control it.

The game is being developed at this moment and this is an BETA version, many things could be changed and new features and levels could be added.

If you experience a crash please report it or let us know directly by email. We’d really appreciate the feedback!

This game is being developed using the great [libGDX](http://libgdx.badlogicgames.com/) library for Android games.
