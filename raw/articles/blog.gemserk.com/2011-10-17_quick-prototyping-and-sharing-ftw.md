Since the beginning of times (of Gemserk), I had one or more local projects where I could test stuff related to the libraries we were using (Slick2D, LibGDX, Artemis), graphical effects, game ideas or just algorithms. One example is the [lighting bolt effect](https://blog.gemserk.com/2011/03/19/lighting-bolts-effect/) I talked about in a previous post, I have also made some [videos](https://www.youtube.com/user/gemserk) of some other tests but never uploaded the code.

As these kind of prototypes could be useful for other developers we have started a **new** project named [prototypes](https://github.com/gemserk/prototypes) (yeah, super creative name) where we (at least I) are going to add some of the new tests and prototypes we make.

To be easily tested by anyone, we created a [Webstart](http://www.gemserk.com/prototipos/prototypes-latest/launch-webstart.jnlp) and an [Android](http://www.gemserk.com/prototipos/prototypes-latest/prototypes-android.apk) application with a launcher to select which test or prototype you want to run.

Hope you like it.
