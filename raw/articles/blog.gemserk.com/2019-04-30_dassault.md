Hi, this is my entry for the Game Jolt Demake Contest, the name is [Dassault](http://gamejolt.com/online/games/action/dassault-game-jolt-demake-contest-droid-assault-demake/2803/) (on the link is the version submitted for the contest). The game selected was [Droid Assault](http://www.puppygames.net/droid-assault/) from Puppy Games. Right now, the game is still on development, although the Contest already finished, because I want to try and learn some techniques based on the original game.

**WARNING**: It could have some (a lot of) bugs because it is an on development version.
