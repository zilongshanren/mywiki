Today was the date limit for the [contest](https://blog.gemserk.com/2010/10/04/game-development-contest-in-uruguay/) we talked about some posts ago, and we can say JSnakes one of the contestants.

Sadly, we are not satisfied with the current state of the game, there are a lot of mechanics we wanted to try but we could not implement them because of serveral reasons. However, one of our main objectives was to at least enter the contest, so that we could establish contact with other developers.

The game version for the contest is on this [link](http://www.gemserk.com/uruguay/concursovideojuegos/2010/jsnakes/launch-webstart.jnlp), you can try it if you want. That version is not going to change if we keep working on the game.
