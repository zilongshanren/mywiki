# SW26010-Pro 架构

SW26010-Pro 是中国神威超算体系的最新一代处理器，于 2020–2021 年设计、在 SC23 超算大会上公开展示。它在 SW26010 基础上扩展规模并升级互联，以争夺 TOP500 前列席位。

## 芯片级结构

芯片由六个核组（Core Group，CG）构成，较上代的四个 CG 增加 50%。每个 CG 含 64 个计算处理单元（CPE），排列在 4×4 网格上，每四个 CPE 共享一个网格节点。一个管理处理单元（MPE）负责线程调度与通信，支持不同特权级和中断，有基本的乱序执行和缓存层次——而 CPE 只运行用户态代码、不支持中断。

单个芯片共 384 个 CPE（全超算系统中有 41,140,224 个，对应 107,136 片），每 256 片组成一个超级节点（Supernode）。

## 执行单元

CPE 是轻量级向量核，强调最大向量吞吐量。向量执行宽度从 256 位加倍到 512 位，时钟从 1.45 GHz 提升到 2.25 GHz，指令缓存从 16 KB 扩至 32 KB。然而每个 CPE 仍无数据缓存，只有一个 256 KB 的软件管理暂存区（其中最多一半可配置为 cache），保持了 Cell BE 式的显式 DMA 访问模型。

## 内存子系统的根本性弱点

每个 CG 配备一个 DDR4 内存控制器（双通道 DDR4-3200，即 51.2 GB/s），六个 CG 合计 307.2 GB/s。相对庞大的计算吞吐量，这一带宽极度不足：FP32 带宽利用率仅约 **0.11 字节/FLOP**，不及消费级 RX 6900 XT（0.23 字节/FLOP）的一半。芯片完全缺乏类似 Fujitsu A64FX 或 AMD CDNA 2 的多兆字节 L2 缓存，也没有 HBM。

与同期对手的对比：

| 系统 | B/FLOP（FP64） |
|------|--------------|
| SW26010-Pro | ~0.06 |
| Fujitsu A64FX | ~0.39 |
| AMD MI250X（CDNA 2） | ~0.25 |

## 网络拓扑

三级树形网络：256 节点/超级节点，超级节点向上连接中央交换网络。每节点对全局互联的有效带宽约 10.54 GB/s，远低于富岳（Fugaku）6D 环面拓扑的 34 GB/s/节点。内存带宽瓶颈还直接拖累了网络利用率——计算与网络传输争抢同一 DDR4 带宽。

## 设计哲学批判

SW26010-Pro 以最大化 TOP500 HPL 排名为核心目标，在算力密度上可观，但代价是：

- 无硬件缓存层次：程序员必须手动管理 DMA
- 极端内存带宽不足：严重限制实际应用效率
- 高优化成本：HPL-MxP 调优需要手动跨 NUMA 分块，在 Frontier/Fugaku 上无需此类工作

文章（[[chipsandcheese-sw26010-pro]]）认为：峰值算力不等于解决问题的效率，Sunway 设计路线牺牲了可访问性和程序员生产力。
