# 重心柏林噪声（Barycentric Perlin Noise）

标准 Perlin 噪声输出单一标量，天然适合二值混合。但当需要在**三种或更多**纹理/生物群系之间平滑过渡时，直接使用多个独立噪声通道会产生结构性缺陷：各通道互不知晓，极值可能同时出现，导致混合权重的和远偏离 1，纹理区域出现异常亮块或暗斑。**重心柏林噪声**通过将噪声的输出约束在 n 维重心坐标空间内来彻底解决这一问题。

## 重心坐标回顾

重心坐标是用若干"靠近某顶点的程度"来描述位置的坐标系——n 个分量均非负，且总和为 1。经典 RGB 三角形中，任意内部点可唯一表示为三个顶点颜色的凸组合。这套坐标系天然对应"按权重混合 n 个元素"的语义。

## 核心算法修改

[[people/boris-the-brave]] 对 Perlin 噪声做了两处改动：

**1. 用重心梯度替换随机梯度**

原始 Perlin 噪声的格点梯度是任意单位向量；重心柏林噪声改为**分量和为零**的单位向量。生成方法简单：随机采样前 n-1 个分量，令第 n 个 = −（其余之和），若不在单位球内则重采，归一化即可。由于"重心点 + 分量和为零的偏移 = 新重心点"，整个噪声插值过程只在重心空间内部运动。

**2. 为整数格点设非零基准值**

原始 Perlin 噪声在整数坐标处固定输出 0，但 0 不是合法重心坐标（分量和为 0）。需要改为在每个格点储存一个重心基准值，并根据所选梯度方向动态计算偏移量：设在该梯度方向上可前进 u 单位、后退 v 单位仍在三角形内，则基准值偏移为 (u−v)/2 × t，梯度幅度缩放为 (u+v)/2 × t，确保插值结果始终在三角形内且均值为 1/n。

## 与 [[classic-shader-noise]] 的关系

单纯形噪声（Simplex Noise）在 2D 中也基于三角格而非方格，因此天然支持重心插值，这是它替代 Perlin 的核心原因之一。重心柏林噪声是在维持 Perlin 框架的前提下，通过梯度约束达到类似效果的工程路径。

## 应用场景

- **多纹理地形混合**：沙地/草地/雪地三路混合，无需额外归一化
- **生物群系划分**：取 n 维输出的最大分量确定区域归属；取前两大可识别过渡带
- **过程化贴图**：任何需要 n 路等权混合的着色器均可使用
