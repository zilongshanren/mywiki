# 动态分屏（Dynamic Split Screen）

多人本地游戏常用的画面处理手段之一。传统做法是固定的水平或垂直分屏，玩家只能清晰看到自己的视野，却难以把握其他玩家与场景的相对位置。动态分屏根据角色在场景中的实际位置来动态切分画面——玩家接近时共用一个摄像机视野，走远后才按两者连线方向切开画面，让玩家在任何时刻都能直观知道对方的方位。

## 概念流程

[[Ted Sie]] 给出的实现思路分为几步：

1. 根据两个玩家的世界位置计算中心点。
2. 计算两点连线方向，作为分割线的法向。
3. 为每台摄像机设置合适的偏移值（沿连线方向向各自玩家偏移）以及裁剪平面（用一块倾斜平面切掉对侧）。
4. 两台摄像机渲染结果按分割线合成到最终屏幕。

## 过渡优化

直接按距离二值切换会产生顿感——"共用视野"和"分屏视野"两态之间摄像机偏差突变。解决方法很直接：**让偏差值随玩家距离平滑变化**，距离近时偏差趋零（退化为共视），距离远时偏差趋最大（完全分屏），中间过渡用一条可调的 shaping 曲线。这实际上是 [[shaping-functions]] 在相机逻辑里的应用。
