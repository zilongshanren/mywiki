# 三角网格（Triangle Grid）

三角网格是一种用等边三角形平铺二维平面的瓦片地图拓扑，在游戏与程序化生成领域相对小众。Boris The Brave 在一篇详细的参考教程中论证：三角网格的数学比六边形网格**更简单**，且在几何属性上有若干独特优势。

## 三坐标系统

三角网格最自然的坐标方案是将平面切分为三组等距平行线（称为 lane），每个三角形格子由它所在的三条 lane 编号 (a, b, c) 唯一确定。对于向上的三角形 a+b+c=2，向下的 a+b+c=1。

这种三坐标系统与六边形"立方坐标"异曲同工：三个坐标看似冗余，但使得邻居、距离、中心位置、点选等操作全部变成极其整洁的线性运算：

- **邻居**：向上三角形的三个邻居是 (a-1,b,c)、(a,b-1,c)、(a,b,c-1)；向下则各加一。
- **距离**：`|a1-a2| + |b1-b2| + |c1-c2|`，无需平方根。
- **中心坐标**：三坐标的线性组合，公式恒定。
- **点选三角形**：对输入点做三次点积后取整即可，无条件分支。

## 为什么值得考虑

**非平面问题**：在方格或六边形网格引入高度图时，四顶点格子容易产生非平面四边形，在光栅化时出现撕裂。三角格的每个格子只有三个顶点，三点永远共面，是天然的地形切片单位。

**组合数更少**：涉及"角"的算法（如 [[game-development/tileset-classification]] 中的 Marching Squares 类型）对三角格只需处理 2^3=8 种基础情形，而方格需要 2^4=16 种；在允许旋转的情况下差距进一步扩大。

**线性插值**：三角格天然支持重心坐标（barycentric coordinates）插值，而方格需要双线性插值，后者在数学上更复杂。单纯形噪声（Simplex Noise）取代柏林噪声（Perlin Noise）的核心原因之一正是利用了三角格（在 2D 中）而非方格的插值优势。

**球面铺砌**：基于三角形可以构造完全均匀的球面网格（如二十面体细分），而方格或六边形在球面上总需要特殊处理的极点或五边形。

## 对偶性

六边形网格与三角网格互为**对偶（dual tessellation）**：六边形的角是三角网格的格子中心，反之亦然。因此，任何"放在六边形角上"的算法其实是在操作三角网格。Boris 的实现中，许多六边形操作是先转换到三角坐标做完后再转回的。

## 与 Sylves / Tessera 的关联

Boris 的 .NET 几何库 **Sylves** 内置了对三角网格的完整支持，其 [[game-development/wave-function-collapse]] 扩展工具 **Tessera** 也因此可以在三角网格上做程序化生成。

关于三角网格的延伸研究还包括：**Trihex（三联六边形）格**（间距加倍即得六边形+三角形交替铺砌）、允许经顶点中转的**替代距离函数**（`(|da-db|+|db-dc|+|dc-da|)/2`，行为接近六边形距离），以及三角列式排列天然对应**等距（Isometric）视图**的几何关系——见 [[sources/boris-triangle-grid-extensions]]。
