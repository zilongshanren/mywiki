# 卡牌构筑游戏的设计套路（Decktamer / Rogue Hex / Dawnmaker）

[[cloudwu|云风]] 在 2025 年 12 月试玩了三款卡牌构筑（deckbuilder）电子游戏后，从游戏设计者视角梳理了这一品类在《[[paradox-grand-strategy-economy|欧陆风云]]》之外他长期关注的另一条支线：**当卡牌构筑这个机制被移植到传统品类（宠物对战 / 4X / 基地建设）上时，哪些设计变化是本质的**。以下三点是他从这三款产品里提炼的共通套路。

## 双卡堆：分离"行动牌"和"资产牌"

传统杀戮尖塔式构筑只有一个抽牌堆：所有新卡都洗入弃牌 / 抽牌堆，靠抽到才能使用。云风认为这套规则在迁移到基地 / 4X 类游戏时会出事——因为**行动和建筑在本质上是不同的**。行动是每回合使用 / 消失的短期决策，建筑应当是永久性的、摆在版图上的资产。

三款游戏给出的是一种"双卡堆"结构：一个手牌堆仍按构筑逻辑洗/抽，另一个市场堆（建筑堆）独立存在，玩家用行动牌打出的"工程点"去市场堆直接购买建筑并**立即摆上版图**，而不是洗入弃牌堆等抽牌。Rogue Hex 缺失这一层（用一次性行动卡模拟建筑），结果是后期数值崩；Dawnmaker 的完整双卡堆把前期卡和后期卡用市场等级严格划分，城镇中心升级才解锁对应的高级建筑——比"市场掉率"这种软控制更可靠。

## 允许玩家主动"花资源抽牌"

杀戮尖塔里抽牌本身是少数卡片才有的技能，所以整局游戏的手牌节奏高度依赖构筑。但在融合了 4X / 建造元素的游戏里，每回合可选行动本来就很多，如果全部依赖抽牌，就会严重压缩玩家决策空间（"今天抽到啥我就打啥"）。三款游戏不约而同引入了**主动刷牌机制**：Rogue Hex 用劳动力同时支付打牌成本和主动抽牌；Dawnmaker 用科技点刷市场。这给玩家一条显式的"用当前回合资源换更多选择"的路径——风险管理本来就是卡牌构筑的核心乐趣之一。

## 用"需求上升"替代 PVE 战斗作为压力源

Dawnmaker 完全去掉了战斗，只有持续增长的粮食 / 危机需求——需求增速和玩家发展规模挂钩，让玩家必须在"长期积累"与"短期续命"之间抉择。这是对传统 roguelike deckbuilder "BOSS 战模式"的一次抽象替换：**核心压力不必由对手提供，可以由系统本身提供**。这个视角延伸出几条设计原则：

- 单局资源种类不必太多（Dawnmaker 只 5 种），不必每种资源都用卡牌表达；
- 传统卡牌规则里资源点"回合内用光、不跨回合"是为了防囤积，但建设类游戏的建造资源**允许跨回合积累**，代价是要给仓储上限——超出仓储自动浪费——才能保留风险管理的张力；
- 玩家可以靠版图摆放技巧成为主要玩法深度，而不是靠行动卡组合。Dawnmaker 三个角色共享同一个卡池但初始卡组不同，就产生了完全不同的流派（密集建筑 vs. 主动触发 vs. 动态拆建），说明**共享资源 + 不同入口**比"每角色独立体系"更容易调平衡。

## 云风眼中的设计要点

- **双卡堆是必要的**，否则 4X / 建造类游戏的深度会被卡牌抽牌逻辑破坏；
- **主动刷牌机制**是把行动选择权还给玩家的关键，避免游戏变成"看脸"；
- **数值越后期越容易崩**是这一品类的通病——Rogue Hex 中盘就出现碾压现象，Dawnmaker 靠"每局生死一线"的严密数值调校避开了；
- 这些启发直接对应他自己未来做 [[soluna-2d-engine|Soluna]] 独立游戏时可能尝试的方向——结合 [[determinism-vs-smart-ai-gameplay|确定性规则]] 与卡牌构筑的风险管理层。
