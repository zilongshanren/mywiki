# UI 作为传达（UI as Communication）

Ben UI 把游戏 UI 视为"把游戏里的想法搬进玩家脑袋"的通道。设计 UI 时先想"如何传达"，再想"传达什么"。不同的传达媒介在理解速度和信息容量上此消彼长：最快但信息量最小的是尺寸与位置，最慢但信息量最大的是文字语义。

## 传达媒介清单

人类是视觉主导物种，大多数传达手段是视觉的：

- **尺寸（Size）**：相对尺寸传达相对重要性。玩家先看大的，再看小的。这是最基础的排序工具。
- **位置（Position）**：玩家按母语阅读顺序扫描。英文玩家会默认"左上第一，右下最后"，位置因此承载顺序与隐含的重要性。
- **形状（Shape）**：与颜色并列的最原始视觉信号。形状本身能传达世界观——Splatoon 用"滴落"的 UI 形状与 Mario 的圆润形状形成对比，直接传递游戏基调。
- **图标（Icons）**：视作带意义的复杂形状。
- **亮度 / 颜色 / 色相**：承载情绪与类别。但 8% 的男性与 0.5% 的女性有色觉异常，颜色不能是唯一线索。
- **纹理（Texture）**：亮度/颜色的变体。
- **声音（Sound）**：失聪、弱听或静音玩家接收不到，只能作辅助通道。
- **运动（Motion）**：任何随时间变化的视觉都能传达状态。
- **震动（Vibration）**：手柄或手机 haptic，仍然只能作辅助。
- **文字语义（Text）**：信息密度最高、阅读耗时最长。受语言能力、年龄、学习障碍影响，易让玩家疲劳。

## 设计原则

- **不要让不重要元素与重要元素同尺寸**——文中示例显示菜单里"开始游戏"与"退出"同大时玩家会卡壳。
- **不要把关键信息压在单一通道上**——颜色、声音、震动任一通道都有用户不可达的情况，至少要有冗余通道。
- 视觉重要度从强到弱：尺寸 / 位置 > 形状 / 颜色 > 纹理 / 运动 > 文字。

## 要传达什么

- 重要性（importance）
- 可交互性（interactivity，"我可以被点"）
- 顺序（先做这个再做那个）
- 设定与主题（setting & theme）
- 世界观价值（values of the world，例：用"肉单位"还是"人名"）
