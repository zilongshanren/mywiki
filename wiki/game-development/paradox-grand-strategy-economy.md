# Paradox 大战略的经济系统（以 EU5 为例）

[[cloudwu|云风]] 在玩了约 270 小时《欧陆风云 5》后，系统性记录了 Paradox 最新大战略的经济模型。他感兴趣的是一种"**微观公式简洁、宏观呈现深度**"的游戏设计范式——EU5 的经济系统是目前他见过最有代表性的样本。下面的归纳以他的两篇游戏笔记为基础。

## 三要素：人口 / 货币 / 商品

EU5 的经济系统由三类基本量构成，**市场**是三者之间的中介：

- **人口**：既是生产力来源，也是需求来源。有阶层（农民 / 劳工 / 市民…），阶层有满意度和影响力。吃不饱饭的人口会饿死，其他需求不满足会产生不满。
- **货币**：不在世界里以资源形式存在，也没有内在价值。它**只是商品流通的中介**。整个世界的物资不会因货币贬值、债务消失、国家破产而改变。换句话说：**钱买不出无中生有的铁**，哪怕全世界都缺铁——只能靠增产。
- **商品**：世界真正的生态基础。上层的一切（军队、建筑、升级）都要消耗商品。

一切商品源自"**原产（ROG）**"——每块地皮上有一种唯一的原材料（类似《异星工厂》的矿石）。只要地皮有人口就能开发，**不受国家控制力和市场接入度影响**。原产以外的商品都是通过"生产建筑 + 人口 + 原料"转换得来的。

## 市场作为中介

世界被切成若干市场，每个市场有**市场中心地区**。市场中心的影响力决定市场向外辐射的范围；每个地区在每个时刻都归属一个唯一市场。这个版图**不同于国家政治版图**——一个国家可能跨多个市场，两个国家也能共享一个市场。

关键机制：

- **市场接入率**：市场中心接入率 100%，越远越低，边远地区甚至为 0。**生产建筑**的效率被接入率打折，但**原产不受影响**——这解释了为什么"单一超大市场"不可行：远离中心的生产建筑效率会归零。
- **供需与价格**：每种商品在每个市场有目标价格（10%~500%），由供需差决定；实际价格按月向目标价格靠拢，速度受物价波动率影响。
- **库存独立于价格**：库存只影响是否还能进口/出口，不影响价格。
- **利润与税基**：商品价格减原料成本 = 利润 → 归属生产人口 → 产生税基 → 一部分进国库，一部分留阶层。

## 贸易：货币本质的体现

市场之间以**订单**形式交易，每个订单像一支商队：

- **贸易容量**来自市场内的贸易建筑。在外国市场修**贸易站**也能带来贸易容量与影响力（代价是占当地人口、产生本地税基）。
- **贸易距离**按市场边界最短距离计算（不是市场中心距离）。贸易容量消耗按距离乘系数。
- **贸易影响力**用于出口紧俏商品时的订单排队。低影响力订单可能被满足 0——但**贸易容量已经被预占**，额外费用照付。所以大容量订单风险更大，战略物资建议**拆成多个小订单分散采购**。
- **自动订单 vs 固定订单**：系统自动订单按利润分配、不易浪费贸易容量；人工固定订单每月执行但失败率更高。

云风认为这正是**货币的本质**：因为原产固定在世界各处、市场必然碎片化、供需差形成价差、价差驱动商品流动——货币只是这套流动的"潤滑剂"。

## 食物：非商品的特例

食物不是一种货物，而是一个**单一标量**（类似钱）。

- 食物来源于带"食物属性"的商品生产副产品，不同原料有不同食物倍率。
- 农民在森林村落虽然生产皮革，但生产行为本身挂了食物产能。
- 空闲劳工默认以低产能自动产粮。
- 食物按**省份**存储（多个地块共享仓库），先充省份仓、再卖市场，不计接入度。
- 市场之间不能单独贸易食物，但有"食物属性"的商品被贸易时会附带食物流动，不产生额外货币流动。

## 铸币：特殊的生产行为

铸币可视作用黄金/白银直接转货币的生产行为，**不占人口、不占地点**，只需国家菜单勾选产能。加大产能会导致通胀——并非印多少钱，而是单位贵金属兑换价值降低。如果整个市场没有贵金属就无法铸币。

## 开荒的经济学

EU5 的殖民开荒和"在已有经济版图上扩张"完全不同。云风总结最关键物资是**铁**：

- 木/石/粘土/沙在所有地块有默认保底产量，市场规模越大供给越稳。
- 铁没有保底：只能在湿地或邻湖地形生产（炭 → 铁 → 工具）。
- 开荒期进口铁比进口工具更划算（铁/工具单位贸易容量相同，但 4 铁换 5 工具）。
- 地块人口 ≥ 5000 升级为城镇后，才能用石头/铜替代铁做工具——这给"石头保底"一条保命路径。
- 后期关键资源是**纸**：纸影响识字率、识字率影响生产率。造纸链条依赖纤维作物/皮革/布匹。

## 税基 vs 税收

玩家最容易误解的是"税率越高越好"。云风的结论：**税基才是国家真实收入**，税收只是玩家可主动支配的部分。留给阶层的钱会自动投入国家发展（虽然方向不一定是玩家想要的），而低税率直接换阶层满意度——"**藏富于民**"。

影响税基的最重要变量是**地区控制度**。从这个意义上，**分封朝贡国比大一统帝国的经济更好**。但政治层面（价值观调配 / 王室集权）又有反向拉扯，这就是 Paradox 设计"两难"的常见结构。

## 为什么这套设计值得研究

简洁的单元公式（供需决定价格、接入率打折、原产固定）在多层嵌套后产生了复杂涌现：市场划分 → 贸易价差 → 殖民路径依赖 → 地缘政治。对策略游戏设计者而言，这是一套"**微观可读、宏观不可解**"的样本——玩家每一步决策都能算清楚，但整局的最优策略无法提前规划。
