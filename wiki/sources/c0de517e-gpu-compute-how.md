# How does GPU Compute work?（Angelo Pesce / C0DE517E）

[[angelo-pesce]] 发表于 2012 年 11 月的短文，发布一份面向「非 GPU 程序员」的 GPU 与 GPU Compute 入门演示文稿。

## 摘要

文章仅为一个演示文稿（slide deck）的发布帖，无独立正文内容。Pesce 花了约一个月时间制作这份 deck，目标受众是不熟悉 GPU 工作原理的程序员，内容覆盖 GPU 硬件模型与 GPU Compute（GPGPU）的基础概念。少数幻灯片面向游戏行业，但整体是通用介绍性材料。文章末尾链接了他之前关于 OpenCL 入门的文章作为配套实验平台。
