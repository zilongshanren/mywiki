# Peaked Technologies: Definition and Some Predictions（Angelo Pesce / c0de517e）

[[angelo-pesce]] 发表于 2024 年 2 月的随笔，提出并阐述"peaked technology"（到顶技术）的概念框架，分析哪些技术与艺术形式已经达到无法再超越的历史顶点。

## 摘要

Pesce 认为技术并非永远线性进步——当市场需求转移、算力提升不再带来质变、且相关文化形式仍然可用时，某项技术或艺术形式就会"到顶"。他列举了若干例子：九十年代的点击式冒险游戏、以 DOS 生产力工具为核心的个人电脑、以 TLOU 系列代表的西方 AAA 单机游戏。

具体的三个必要条件是：① 市场已经迁移；② 算力的进一步提升不再能带来质性差异；③ 文化形式足够稳定，过去的产品仍可直接消费。文章并不意在悲观，而是指出已到顶的技术实际上**消除了"必须升级"的焦虑**，成为学习与钻研的稳定基点——就像 C64 之于 demoscene。

## 关键要点

- 到顶技术的三个判据：市场迁移 + 算力边际归零 + 文化形式稳定
- 点击式冒险游戏是最典型案例：写作与谜题设计才是核心，3D 图形的提升并未带来质性改变
- 西方 AAA 单机（以 TLOU2 为例）可能正在接近顶点；单人游戏本身不会消亡，但"索尼式、几千人精心打磨"的体验形式很可能不可再现
- 个人电脑从家庭生产力工具演变为专业工具，PC"大众化"时代已过顶
- Windows 在 OS 层面同样接近顶点：垄断消除竞争，缺乏动力保持纯洁
- 到顶后的技术是"稳定的历史锚点"，对学习者反而有利
