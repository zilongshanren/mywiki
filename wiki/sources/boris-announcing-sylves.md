# Announcing Sylves（Boris The Brave）

[[boris-the-brave]] 发表于 2023 年 2 月的库发布公告，介绍面向 C# / Unity 的网格几何库 **Sylves**。

## 摘要

这是一篇简短的发布公告，宣告 Sylves 正式上线。Sylves 是 Boris 多年网格与程序化生成项目经验的结晶，专门处理 C# 或 Unity 中各类网格的几何操作，为网格相关的任何需求提供坚实基础。公告内容极简，指向官方文档站点（boristhebrave.com/docs/sylves/1/）。Sylves 在后续的许多 Boris 文章中（尤其是无限网格、替换铺砖等）被反复引用。

## 关键要点

- Sylves 是 C# / Unity 网格几何库，处理各类网格的几何操作
- 凝结了 Boris 在多个网格项目（WFC、程序化生成等）中积累的知识
- 文档地址：boristhebrave.com/docs/sylves/1/
