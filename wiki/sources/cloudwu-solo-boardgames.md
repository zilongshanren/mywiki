# 介绍几款单人桌游（云风 / blog.codingnow.com）

[[cloudwu|云风]] 发表于 2026 年 1 月 24 日的笔记。沉浸 dotAGE 后，他去桌游领域寻找气质相近的单人游戏，试玩了 Spirit Island (2017)、Voidfall (2023)、Agricola (2007)、ISS Vanguard、Robinson Crusoe、Civolution (2024) 和轻量卡构 Friday (2011)，重点讲了 Spirit Island 和 Voidfall。

## 摘要

**Spirit Island** 是云风花时间最多的一款（Steam 有官方电子版、BGG 总排名高）。背景像电影《阿凡达》：岛之灵魂通过原住民驱赶殖民者。每回合按"神力成长 → 玩家行动 → 殖民者入侵 → 成长 → 破坏"固定次序循环；殖民者入侵地点有轻微随机性，但随后两回合的破坏路径是确定的，玩家有两回合准备窗口。它的特点是**完全确定性战斗 + 小卡池 + 法力点跨回合不清零 + 抽牌零随机**——法术只在从市场加新能力时才有一点随机，一旦进入牌组玩家 100% 控制使用时序。云风认为这套规则让整局游戏变成"精确打出每回合那少数几张卡片"的时序规划问题。

**Voidfall** 结构更接近 dotAGE：完全无战斗、纯跑分，玩家在军事/经济/科技/政治四方向议程中选得分路线；游戏分三阶段，每阶段一张事件卡引导得分手段——和 dotAGE 的"预言"机制一致，也和 dotAGE 的季节交替末日来临类似，**用规则节奏强制区分开发→扩张→冲刺**三段。无官方电子版，用 Tabletop Simulator mod 玩。

云风同时指出这一品类（dotAGE / Spirit Island / Voidfall）的共同点和差别：都以**精算规划应对确定风险**为核心乐趣；但电子化游戏（dotAGE）可以一整天长回合 + 超高难度仍有容错，而桌游必须短回合快节奏、容错大幅下降。Spirit Island 在少数行动里塞复杂多样性、法术功效变得过于晦涩（字面清楚、设计逻辑难懂），这是 dotAGE 做成电子化能比类似桌游更宜人的根本原因。

末尾推荐轻量卡构 **Friday (2011)**：5 分钟规则、一组卡就够、但玩 20 盘才找到胜利诀窍。其特别处是**整个机制把重点放在卡组瘦身**——玩家主要考虑如何精简掉初始卡组里低效的卡，而非加强加卡。这是对 roguelike deckbuilder 惯性思维的反向设计。

## 关键要点

- Spirit Island：确定性战斗 + 小卡池 + 法力点跨回合积累 + 抽牌零随机
- 小总牌量让每张卡有决定性作用，和杀戮尖塔大卡池逻辑完全不同
- Voidfall 三阶段 + 四方向议程 = 电子化 dotAGE 之外的桌游结构
- dotAGE 类似电子化 Agricola（2007 经典工人分配游戏）
- 电子游戏 vs 桌游：电子允许长回合 + 超高难度容错，桌游必须短回合快节奏
- Spirit Island 法术设计逻辑晦涩——设计复杂性高但玩家理解成本大
- 云风不偏爱确定性战斗，骰子式风险管理（ISS Vanguard / Robinson Crusoe / Civolution）也同样喜欢
- Friday：卡组瘦身为核心的反向卡构设计
