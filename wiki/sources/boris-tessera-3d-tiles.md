# Tessera 3D Tile Level Generation（Boris The Brave）

[[people/boris-the-brave]] 发表于 2019 年 11 月的公告文章，宣布其首个商业产品 **Tessera** 在 Unity Asset Store 上线。

## 摘要

Tessera 是基于 [[game-development/debroglie-wfc-library|DeBroglie]] 库构建的 Unity 插件，允许设计师通过配置一套 3D 瓦片，让引擎自动程序化生成关卡。核心技术来自 DeBroglie（Boris 此前开源的 WFC/.NET 库），但商业版本在 UI 打磨、示例内容和文档质量上投入了更多精力。文章篇幅极短，主要是发布公告，技术细节已在 DeBroglie 相关文档中覆盖。

## 关键要点

- Tessera 是 DeBroglie 的 Unity 前端封装，核心算法为 WFC（Wave Function Collapse）
- Boris 明确表示此次更多精力用于 UI、示例和视频制作，而非新算法
- 定位为"通用关卡生成器"，有望成为 Asset Store 中该类别的标杆产品（用户评语）
- 后续计划继续将 DeBroglie 的更多功能移植进来
