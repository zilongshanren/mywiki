# 1 more screen of Design Garage（Sam Lapere, 2010-05-01）

[[sam-lapere|Sam Lapere]] 一则极短的观感博客：他从 EVGA 论坛扒了一张 NVIDIA *Design Garage* 车库内景截图，觉得这张静物室内渲染"让我想起 Cinema 2.0 / OTOY / Ruby demo"。

## 摘要

几乎没有技术内容。Lapere 借这张图对比了 AMD 的 Cinema 2.0 / Ruby 路径追踪演示——抱怨"过了 2 年 AMD 再没提过 Cinema 2.0"，暗含他对 *Design Garage* 这种"**能下载的 tech demo**"比只剩 PR 的 Ruby 更看重。评论区网友补一刀："OTOY/Ruby demo was vaporware. Garage is real"。唯一可记的点是 Lapere 看重的"**真正跑在消费卡上的可交互 demo** > PR 视频"这种标准，跟他 3 月 Fermi 帖里对 AnandTech 实测 8.7× 提升的兴奋是一致的。

## 关键要点

- Design Garage 静物室内场景与 OTOY/Ruby Cinema 2.0 风格相近
- Lapere 的潜台词口径：可下载可交互 > PR 视频
- 文章只是时间线档案，无新技术信息
