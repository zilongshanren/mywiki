# PCA for Programmers（Alan Zucconi）

[[alan-zucconi]] 2025 年 1 月的教程系列开篇。主题是主成分分析 (PCA)——一个被无数统计课程讲糊了的线性代数工具。Zucconi 的写法延续他 shader 系列的风格：先给读者可交互的 2D 直观展示，再推到实际的鸢尾花数据集与特征值分解。

## 摘要

文章从「一个矩形旋转时它的投影宽度会变」引入：PCA 本质上就是在寻找让数据**投影方差最大**的方向。在 2D 玩具数据集上，作者让读者拖动旋转角度，看 X 轴上投影的 spread 如何变化——最大方差对应的方向就是**第一主成分**。之后把同样的几何直觉推广到 N 维：PCA 不断找残余空间中方差最大的方向，得到 N 个正交主成分，等价于协方差矩阵的特征向量，每个特征值就是该方向的方差。应用示例是 Fisher 鸢尾花数据集：4 维原始特征（花萼长、花萼宽、花瓣长、花瓣宽）经 PCA 投影到前两个主成分后，三个物种在 2D 散点图里就已视觉可分离。文章明确声明这只是第一篇（「no maths」版），后续将写推导与实现。

## 关键要点

- PCA = **坐标系旋转**，使得前 k 个新轴覆盖尽量多的原始方差。
- 几何直觉：把数据点拟合成一个椭球，主成分就是椭球的**三个半轴方向**，特征值是半轴长度的平方。
- 用途：**降维**（压缩可视化）、**去相关**、**噪声滤除**（最小方差方向往往是噪声）；不适合非线性流形数据（那是 t-SNE / UMAP 的地盘）。
- Zucconi 刻意避免数学，用交互图代替推导——延续他对「直觉先于公式」的教学观。
