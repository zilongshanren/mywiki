# Branimir Karadžić

Branimir Karadžić 是一位图形与引擎程序员，最广为人知的身份是开源跨平台渲染库 **bgfx** 的作者。早年参与 Carbon Games 的 AirMech 开发，负责将游戏移植到 Native Client、OpenGL ES 等平台，这段经历也催生了他对 [[middleware-vs-open-source]] 与跨平台渲染抽象的思考。

他长期主张一种务实、反时髦的 C++ 风格，写下了广泛流传的短文 [[orthodox-cpp]]（又称 C+），主张只使用那些能真正改进 C 的 C++ 特性，拒绝 RTTI、异常、iostream、重度模板元编程等"现代 C++"特征。这一风格与 [[cpp-multi-paradigm-discipline]] 的自律取向一致，也影响了 dear imgui、DOOM 3 BFG 等项目在代码风格上的选择。
