# Patrick Stein

nklein software 博主，笔名 Pat / nklein。资深 Common Lisp 爱好者，长期在 CL-OpenGL、ZPB-TTF、userial、cl-fft、cl-growl 等 Lisp 库上做工具型贡献，也是 TC Lispers（Twin Cities Lispers 用户组）的活跃成员。博客文章覆盖从 Lisp 宏、CLOS、序列化到 OpenGL 字体渲染、光线追踪（2024 年用 Lisp 重写 Ray Tracing in One Weekend 并扩展到 n 维 CSG）。

2010 年前后短暂跨界 Objective-C / iPhone SDK，发布 Spelling Toy 儿童拼写 app，但写作重心仍在 Lisp 生态。
