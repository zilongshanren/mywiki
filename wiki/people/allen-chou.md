# Allen Chou（周明倫）

Allen Chou（Ming-Lun "Allen" Chou，周明倫）是一位台湾出身的游戏程序员，自 2014 年从 DigiPen Institute of Technology 毕业后加入 [Naughty Dog](https://www.naughtydog.com/) 担任 gameplay programmer，据他本人描述是 Naughty Dog 历史上第一次给应届本科生发 offer。他在博客 `allenchou.net` 上长期维护一个 **Game Physics Series**，把自己在 DigiPen 做 junior project 物理程序员时学到的约束式刚体物理引擎知识一篇篇写出来，为后人梳理了这片向来被视为「部落知识」（tribal knowledge）的领域——没有单本书能覆盖全部细节，靠的是 GDC 讲座、论坛讨论和开源引擎（Box2D / Bullet）源码自学。

在加入 Naughty Dog 之前，他在大学四年级之前还做过 ActionScript 3 生态里的若干小型开源项目：**Bunnyhill**（一个基于 Flash Molehill API 的 2D 场景图渲染引擎）、**Stardust**（粒子引擎）和 **Rusher 2**（ECS + 命令模式的轻量游戏框架）。这些早期博客文章虽然技术栈已经过时，但命令模式、序列/并行子命令等设计思想至今仍是游戏系统架构的基本词汇。
