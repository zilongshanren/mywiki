# John Ousterhout

**John Ousterhout** 是斯坦福大学计算机科学教授，A Philosophy of Software Design（APoSD）的作者。

## 主要贡献

- **A Philosophy of Software Design**——把软件设计哲学系统化的书，反驳了 Clean Code 和设计模式传统里的一些教条，提出了 [[complexity]]、[[deep-modules]]、[[information-hiding]] 等核心框架。
- 软件设计课的长期教学经验，观察了大量学生代码和工业级系统的腐化过程。

## 核心观点

- 软件开发的根本限制是**理解系统的能力**（认知限制），不是技术限制。
- [[complexity]] 是软件设计的核心敌人，以 [[change-amplification]]、[[cognitive-load]]、[[unknown-unknowns]] 三种症状出现。
- [[deep-modules|深模块]]优于浅模块，[[classitis]] 是一种流行病。
- 接口是成本，功能是收益。

## 与其他经典的对比

- 对「函数要短」「类要小」这类 [[classitis|Clean Code 教条]]提出了明确质疑。
- 他的书提供的是**思考框架**，而不是规则集合。
