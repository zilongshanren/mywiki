# Alex Harri Jónsson

冰岛软件工程师，自 2018 年起从事 Web 与产品方向开发，先后效力于 Taktikal、GRID、Arkio，现就职于 NeckCare。博客 [alexharri.com](https://alexharri.com/) 以深挖技术细节、大量交互图示见长，代表作包括《The Engineering behind Figma's Vector Networks》《Planes in 3D space》与《The web's clipboard》。他的风格是「拿一个具体、看似琐碎的小问题挖到底」：从 Web 剪贴板 API 的历史，到压缩冰岛人名变格的 trie，到把 ASCII 字符当作形状向量的渲染器，每一篇都带着代码、数据与可交互演示把问题讲透。
