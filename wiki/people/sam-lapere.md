# Sam Lapere

Ray Tracey 博客（`raytracey.blogspot.com`）作者，GPU 路径追踪长期记录者。曾参与 OTOY 生态（Octane Render、Brigade real-time path tracer 的早期演示与 tech demo），后加入 NVIDIA，从旁观者转为内部从业者，持续跟踪消费级 GPU 上的 unbiased rendering 进程——从 2010 年 Fermi 的光线追踪 buzz，到 2018 年 Turing 的 RT Core，再到 Omniverse / Racer RTX 这一代"实时、近乎无噪"的路径追踪平台。

博客的价值更多是**时间线档案**而非技术教学：他会把学术论文、Jacco Bikker 的 Brigade / [[lighthouse-2-optix|Lighthouse 2]]、NVIDIA 的产品节点穿在一条叙事线上，这是当下路径追踪产品史难得的一手视角。
