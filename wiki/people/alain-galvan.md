# Alain Galvan

AMD 的光线追踪驱动工程师，活跃的图形 API 布道者和技术写手。以系列"Raw"入门文章著称：通过最小化 Hello Triangle 程序逐步拆解 DirectX 11、DirectX 12、Vulkan、Metal、WebGPU 等现代图形 API 的初始化流程，帮助读者建立对底层 API 的直觉。同时维护 CrossWindow、CrossWindow-Graphics 等跨平台窗口/图形工具库。
