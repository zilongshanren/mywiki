# Cyan（Cyanilux）

Cyan（Twitter `@Cyanilux`）是活跃在 Unity 社区的独立技术美术和 shader 教程作者，博客原来放在 `cyangamedev.wordpress.com`（后来迁移到 `cyanilux.com`）。他最为人熟知的是 **Shader Graph 教程**和 **URP（Universal Render Pipeline）后处理、Renderer Feature 相关的开源代码**——包括 [`URP_BlitRenderFeature`](https://github.com/Cyanilux/URP_BlitRenderFeature) 和 [`URP_RetroCRTShader`](https://github.com/Cyanilux/URP_RetroCRTShader) 等多个被社区广泛 fork 的仓库。

他的写作风格比较朴素——手把手讲清楚 Shader Graph 里每个节点的语义、边界条件、以及和底层 HLSL 的对应关系，是 Unity shader 新手圈里被转发最多的入门材料之一。他也经常参与 [[harry-alisavakis|Harry Alisavakis]] 主办的 `#TechnicallyAChallenge` 技术美术挑战赛——[[crt-shader-effects|复古 CRT shader]] 就是为其中"Retro"主题做的作品。
