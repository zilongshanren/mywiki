# Jiayin Cao (A Graphics Guy's Note)

华人图形程序员，曾任职 Sony Naughty Dog，现服务于 NVIDIA，在 Zorah（RTX 50 旗舰 demo）为 NvRTX / Unreal Engine 贡献基于 ReSTIR PT 的全局光照实现。业余时间维护离线渲染器 [SORT](https://sort-renderer.com) 与 [Tiny Shading Language (TSL)](https://tiny-shading-language.com/)。博客 `agraphicsguynotes.com` 以少而深著称——十年更新十余篇，每篇都把一个主题彻底讲透（BDPT 的 MIS 实现、SSS 实践、ReSTIR 背后的数学、Fiber 的 C++ 实现等）。

写作风格偏教学：从数学与直觉双线切入，不回避推导，专门补齐论文没写清楚的隐含条件。
