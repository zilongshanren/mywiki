# Gemserk

Gemserk 是一家独立游戏工作室，核心成员 Ariel Coppes（[@arielsan](https://twitter.com/arielsan)）是主要博客作者。团队长期使用 Unity 开发中小规模项目，在 Ludum Dare 等 game jam 上积累了大量工程实战经验。

博客 `blog.gemserk.com` 的内容偏向**Unity 工程实践**：Input System 调研、Prefab/GameObject 作为数据容器的用法、Unity ECS/DOTS 的调试工具、Prefab 与 Scene 中数据的批量重构。文章普遍带可运行的 GitHub 示例仓库，对实际项目中的"踩坑"交代得比较直白。
