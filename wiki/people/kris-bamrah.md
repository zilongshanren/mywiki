# Kris Bamrah

**Kris Bamrah** 是 PlayCanvas 团队成员，负责团队工具链的开源沟通与工具类产品公告。在 blog.playcanvas.com 上他署名的两篇——**Editor Frontend 开源**（2025-07）和**VSCode Extension 新版**（2025-11）——把 PlayCanvas "全链路向开发者开放" 的策略讲清楚：Editor 前端改开源、VSCode 插件把项目结构直接 disk-mapped 到本地让 AI agent 可介入。这两篇串起来是一条"让 PlayCanvas 项目从只能在 Web Editor 里改，变成可以被任何主流 dev 工具链管控"的线。

## 主要贡献

- 主导 PlayCanvas Editor Frontend 开源公告（`github.com/playcanvas/editor`）及配套的代码重组、TypeScript 强化、测试套件等贡献门槛下降工作。
- 负责新一代 **PlayCanvas VSCode Extension** 的发布与推广：实时 sync、live collaborators、完整 TS 类型检查、Disk-mapped file system（AI-agent 友好）。
