# Nikos Papadopoulos（Arkanova / 4rknova）

**Nikos Papadopoulos**（handle **Arkanova**）是希腊图形程序员 / demoscene 爱好者，个人站 [4rknova.com](https://www.4rknova.com/) 以 Linux 工具链笔记、GLSL/ShaderToy demo 和光栅化小品为主。博客从 2012 年开始，内容多为短文和代码片段——适合做"冷知识库"而非长篇教程。他的 demos 页收录了大量分形、L-system、distance-field、demoscene 经典效果（plasma、tunnel、twister、fire）的 GLSL 实现，以及 PS1 风格光栅器、高斯溅射点云、mass-spring 布料等实验。

## 风格

- **短而实用**：单文往往 20-80 行，给出一个可跑的最小示例或一段 shell alias。
- **工具链导向**：GNU make 并行、Debian NVIDIA Optimus (primus)、资源嵌入等 Linux 开发细节。
- **GLSL demo 为主**：ShaderToy 风格 fragment shader，偏教学不偏优化。
