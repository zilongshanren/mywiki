# Jon Olick

前 id Software 程序员（Quake 2 时代），JO JPEG / jo_*.h 系列单文件库作者。在图形、图像处理、压缩、神经网络超分等多个方向持续输出，偏好 STB 风格的 header-only C 库和"一个概念、一个文件"的极简工程美学。博客 jonolick.com 上有大量关于 DXT/BC 压缩、HDR 视频、AI 图像超分、索引缓冲压缩、error diffusion、SIFT 等主题的实践笔记。
