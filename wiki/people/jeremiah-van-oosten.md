# Jeremiah van Oosten

荷兰/加拿大图形程序员，博客 [3D Game Engine Programming](https://www.3dgep.com/) 的作者，任教于 Breda University of Applied Sciences 游戏编程课程。他以系统性的长篇技术教程见长，覆盖 DirectX 11/12、CUDA、OpenGL 以及 3D 数学基础。他的 DirectX 12 系列教程是当前中文与英文圈里少见的从 API 原理到工程封装一步步讲透的实战材料，GitHub 仓库 `jpvanoosten/LearningDirectX12` 承载对应代码。

## 主要贡献

- **Learning DirectX 12** 系列教程：从 Hello Triangle 到 render graph / PBR，逐步构建一个可复用的 D3D12 框架
- **CUDA 系列文章**：线程执行模型、内存模型、常用优化模式（tiling、shared memory）
- **C++ Fast-track for Games Programming**：本科游戏方向的入门快车道课程
- 3D 数学、OpenGL、以及 Blender 插件开发等配套教程
