# Elias Daler

独立游戏开发者，自有引擎 **Edbr** 与 2D 动作冒险游戏 **Re:creation** 的作者，长期在个人博客 eliasdaler.wordpress.com（后迁至 GitHub Pages）记录引擎与脚本系统的实现笔记。早期文章以 SFML + C++ 为基础，重点讨论如何把 Lua 嵌入 C++ 项目用于配置、热加载和游戏数据驱动，是英文社区里讲解 Lua/C++ 绑定最常被引用的入门系列之一。
