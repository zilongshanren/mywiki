# 读 Shader 相关数学论文的记号速查

Xor 在 Reading Math Papers 写给自学者的一份**记号字典**：shader 作者迟早要啃 rendering equation、微表面 BRDF、球谐等论文，而数学家的写法和 GLSL 不一样，卡点经常在符号而不是概念。

## 基本记号

- **标量**小写字母 `a, b`；**向量** bold `**v**` 或 `v⃗`，组件写下标 `v_1, v_2` 或 `x, y, z`。
- **单位向量**加帽子 `â`，定义 `â = v⃗ / ‖v⃗‖`。
- **矩阵**大写 `A`，方括号罗列元素。
- **张量**是上面所有概念的推广：0 阶标量、1 阶向量、2 阶矩阵、更高阶就是多维数组。

## 运算

- 相邻变量 `ab` 默认相乘；点 `·` 和叉 `×` 分别是[[vector-dot-product|点积]]和叉积，**不要**和算术乘号混淆。
- `|x|` 是绝对值，`‖v‖` 是向量长度。
- Σ 是求和（相当于 for-loop 累加），∏ 是连乘。
- 布尔：∧ (AND)、∨ (OR)、¬ (NOT)、⊕ (XOR——Xor 笔名的由来)。

## 函数与映射

- `f(x) = …` 是普通定义；`sin x` 省略括号是因为无歧义。
- `f⁻¹` 是反函数（前提是一一映射，`x²` 就没有全局反函数）。
- **Arrow notation**：`x ↦ x+1` 是「把 x 映到 x+1」的 inline 函数；`→` 是「集合到集合的映射」。
- 对 shader 常见场景，比如 `sgn: ℝ → {-1, 0, +1}`，直接翻译成 if-else 即可。

## 集合与区间

- ℕ / ℤ / ℚ / ℝ / ℂ —— 自然数 / 整数 / 有理数 / 实数 / 复数。GLSL `int`≈ℤ、`uint`≈ℕ₀、`float`≈ℚ 的近似。
- ℝ⁺ 只含正实数；∅ 是空集；`{a,b,c}` 是有限集（比如 `sign` 的值域）。
- **区间**：`[a, b]` 闭（含端点），`(a, b)` 开（不含）。一个常被忽视的实用例子：`fract(x)` 的值域是 `[0, 1)`——0 取到、1 取不到。
- `∈` / `∉` 表示「属于 / 不属于」某集合。

## 为什么值得知道

很多论文只在第一页扔一堆符号就开始堆公式，看不懂记号会被劝退。这页不是教数学，而是做成一张**查表**：遇到生僻符号先来这里核对，再回到论文。和 [[faster-math-functions]]、[[spherical-integration]]、[[microfacet-brdf]] 这些论文导向的页配合使用最香。
