# 射影叉积：点、直线、平面的对偶运算

在欧氏空间里，叉积通常只被当作「求法线」的工具。但在齐次坐标系下，叉积还有一组更不常被提及的性质：它是连接**点**与**直线**（2D）乃至**点**与**平面**（3D）的桥梁，可以把求"两点共线方程"和"两线交点"这两件事统一成同一个算子。

## 2D：点与直线的对偶

取两个 2D 点 $p_0(x, y)$ 和 $p_1(x, y)$。先把它们提升为齐次形式，各自补 1：$p_0 = (x_0, y_0, 1)$，$p_1 = (x_1, y_1, 1)$。

三维叉积 $\ell = p_0 \times p_1$ 得到的向量 $(\ell_x, \ell_y, \ell_z)$ 恰好就是过这两点的**直线方程**——对应于隐式形式 $\ell_x \cdot x + \ell_y \cdot y + \ell_z = 0$。结果未归一化，实际使用时通常将 $(\ell_x, \ell_y, \ell_z)$ 除以 $\sqrt{\ell_x^2 + \ell_y^2}$ 使 $|(\ell_x, \ell_y)| = 1$，此时 $\ell_z$ 表示原点到直线的有符号距离。

反过来，给定两条直线 $\ell_0$ 和 $\ell_1$（各以三维向量表示），再做一次叉积：$p = \ell_0 \times \ell_1$ 即为两直线的**交点**（齐次坐标），除以第三分量 $z$ 即得笛卡尔坐标。

结论简洁：**叉积把两点变成直线，把两直线变成交点**，且这两件事的运算形式完全一样。

## 3D：点与平面的对偶

同样的思路在三维成立，只是维度升高一阶。取三个 3D 点 $p_0, p_1, p_2$，各补 $w=1$ 升为四维齐次坐标。定义**四维叉积**（三向量版本）：

$$\Pi = \text{cross4D}(p_0, p_1, p_2)$$

结果向量 $(\Pi_x, \Pi_y, \Pi_z, \Pi_w)$ 就是过这三点的**平面方程**，满足 $\Pi_x x + \Pi_y y + \Pi_z z + \Pi_w = 0$。同样可以归一化：除以 $|(\Pi_x, \Pi_y, \Pi_z)|$。

反向操作：给定三个平面 $\Pi_0, \Pi_1, \Pi_2$，再做一次四维叉积，结果是三平面的**交点**（齐次坐标），除以 $w$ 分量还原为三维笛卡尔点。

四维叉积的展开式如下（每个输出分量是另三个分量的 $2\times 2$ 行列式组合）：

```c
void cross4D(const float v1[4], const float v2[4], const float v3[4], float r[4]) {
    r[0] =  v1[1]*(v2[2]*v3[3]-v3[2]*v2[3]) - v1[2]*(v2[1]*v3[3]-v3[1]*v2[3]) + v1[3]*(v2[1]*v3[2]-v3[1]*v2[2]);
    r[1] =  v1[0]*(v3[2]*v2[3]-v2[2]*v3[3]) - v1[2]*(v3[0]*v2[3]-v2[0]*v3[3]) + v1[3]*(v3[0]*v2[2]-v2[0]*v3[2]);
    r[2] =  v1[0]*(v2[1]*v3[3]-v3[1]*v2[3]) - v1[1]*(v2[0]*v3[3]-v3[0]*v2[3]) + v1[3]*(v2[0]*v3[1]-v3[0]*v2[1]);
    r[3] =  v1[0]*(v3[1]*v2[2]-v2[1]*v3[2]) - v1[1]*(v3[0]*v2[2]-v2[0]*v3[2]) + v1[2]*(v3[0]*v2[1]-v2[0]*v3[1]);
}
```

## 与计算机视觉的渊源

这套技巧来自**射影几何**（projective geometry）和计算机视觉中的**对极几何**（epipolar geometry）。在对极几何里，一张图里的一个像素点对应另一张图里的一条对极线，而这条线可以通过叉积乘以本质矩阵（Essential Matrix）求出。[[jonolick-cross-product-tricks]] 的价值在于把这个思想从视觉领域迁移到图形编程的日常工具箱：**凡是需要「两点确定直线」或「两线求交」的代码，都可以用叉积代替手动推导**。

实际应用场景包括：碰撞检测中求两平面的交线、构建线段-平面的交点、参数化直线方程与光线检测等。与 [[homogeneous-rasterization-transpose-bug]] 描述的齐次坐标光栅化技巧属于同一族思维工具。
