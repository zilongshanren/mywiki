# Solid Motion —— 沿动画时间轴扫掠 mesh 生成实体雕塑

**Solid Motion** 是 [[joost-van-dongen]] 2006 年写的一个 MAXScript 技术，用来把 3ds Max 里的一段 mesh 动画**压缩成一个静态 3D 实体**：这个实体的体积恰好等于动画过程中原物体所扫过的全部空间。本质是**时间维度塌缩为一层几何表面**——把 4D（3D + 时间）投影到 3D。

## 算法

朴素到一句话能讲完：

1. 遍历动画每一帧，**复制**当前帧的 mesh；
2. 对相邻两帧，**在每一条对应 edge 之间**生成一个 quad polygon 把两帧的 surface 封起来；
3. 所有这些 quad + 所有帧的 mesh 拼在一起 = Solid Motion。

没有任何解析曲面拟合，没有体素化，没有 marching cubes——就是逐帧复制 + edge 连接。代价是面数爆炸（一个实例可以到 4M+ 三角形），但因为只用来**离线出图**而非实时渲染，作者不在乎。

这套思路在早期 POV-Ray 社区有一个近亲：`sphere_sweep` 沿一条曲线扫掠出的管状体。Solid Motion 的推广在于**扫掠对象不是球而是任意变形 mesh**，**扫掠路径不是显式曲线而是隐含于动画曲线里的每一个顶点**。

## 伪像：子采样鳞片

如果动画里只有**纯平移**，相邻帧 edge 到 edge 的线性插值是精确的——生成的侧面完全平整。

一旦动画里**同时有旋转 + 平移**，相邻两帧同一条 edge 之间的真实扫掠轨迹是曲面（螺旋片段），直接 edge 插值只给了一条**弦**。结果是在侧面形成规则的鳞片状折痕——面数越高、帧数越密，鳞片越小；反过来密度低就明显。

严格修掉需要**自适应采样**（速度快的区段塞更多帧）或**在两帧之间插入真实曲面片段**，面数要抬到 10M 级。Joost 选择**不修**——他把这些鳞片当作纹理图案，是表面「可看性」的来源。这个取舍是[[games-as-expression]]里「作者审美优先」主张的一个具体落地。

## 何时有用

1. **从动画生成抽象静物海报** —— 把一个具象动作（茶壶落地、柱子倒塌）瞬间变成构图复杂的抽象雕塑；
2. **从 Futurism 式「运动即形式」命题出发的艺术项目** —— 这是 Joost 自己的出发点；
3. **离线展示运动轨迹的调试可视化** —— 例如看一个 IK 解算或物理模拟到底扫过了哪些空间；
4. **给程序生成几何体找新灵感** —— 任何能「插值两份 mesh 的对应顶点」的 pipeline 都能出 Solid Motion 效果。

不适合实时渲染（面数）、不适合需要干净侧面的 CAD 类输出（会有鳞片）。

## 更一般视角

把 Solid Motion 放到过程建模谱系里：

- **sphere sweep / tube**：沿曲线扫单一剖面；
- **lofting / skinning**：在若干离散剖面之间插值；
- **metaball / SDF union**：隐式域 Boolean 并；
- **Solid Motion**：在**时间轴**上把同一个 mesh 的每一帧做 skinning；

它的位置是：对**时间+变形**这种扫掠输入最直接的「朴素表示」，以最低实现复杂度换取几何表现力。
