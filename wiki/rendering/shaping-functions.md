# 塑形函数（Shaping Functions）

**塑形函数**指在着色器中把一个标量输入（通常是 UV 坐标、时间或纹理采样值）映射为另一个标量输出的基础数学工具。它们是程序化着色器的「字母表」：单独看都很简单，但互相组合就能表达大量视觉效果，甚至完全脱离纹理采样。[[fragment-shader]] 的大量技巧都建立在熟练使用这些函数的基础上。

## 典型函数

**Step 与 Smoothstep**。`step(a, b)` 是硬阈值：`b >= a` 返回 1，否则返回 0，常用于遮罩与二元比较。`smoothstep(a, b, x)` 则在 `[a, b]` 之间给出一段三次多项式 `t*t*(3-2*t)` 的平滑过渡，用于需要柔边而不是锐边的情况；当 `a == b` 时它退化为 step。Smoothstep 的导数在端点处连续为零，因此是避免走样（参见 [[aliasing]]）、生成软阴影、抗锯齿边缘的首选。

**Lerp/Mix 与逆 Lerp**。`lerp(a, b, t) = (1 - t) * a + t * b` 是颜色与数值混合最常用的原语；搭配任何能映射到 `[0,1]` 的参数（UV、时间、噪声、纹理）都能产生渐变。HLSL 内置的 `lerp` 与 GLSL 的 `mix` 是一回事。**Inverse Lerp** 做相反的事情——给定 `x`，返回它在 `[a,b]` 之间对应的 `t`，用于把任意区间重映射到 `[0,1]`。Unity HLSL 没有内置 invLerp，需要手写 `(x - a) / (b - a)`。

**Sin/Cos**。三角函数天然周期，是做「呼吸」「脉动」「水波」「光闪」等循环动画的基础。它们的参数是弧度，所以一般会乘以 π 或 τ 让频率更直观；返回值在 `[-1, 1]`，在需要非负值时要重映射到 `[0, 1]`。

**Frac/Fract**。`frac(x)` 返回小数部分，图像上是锯齿波——当任何值会超出 1（比如世界坐标、深度），`frac` 能把它周期性地折叠回 `[0,1)`，对着色器调试与平铺效果都很有用。把锯齿波转成三角波只需 `abs(frac(x) - 0.5) * 2.0`，就能得到一条线性往返的周期信号，区别于 sin 的平滑过渡。

**Min/Max、Floor/Ceil** 这些基础函数与上面几个搭配使用，能构造阶梯、网格、量化等效果。

## 时间维度

着色器之所以能驱动动画，一大原因就是环境提供的「时间」统一变量。Shadertoy 里是 `iTime`，Unity ShaderLab 里是 `_Time.y`。把 `time` 加到上述任何函数的输入里——比如 `sin(uv.x * PI + time)`——就能让静态渐变立即变成滚动波形。这种「UV + 时间」的模式是大多数简单动态材质的核心套路。

## 延伸

这些函数的真正威力在组合。给 `lerp` 喂一个 `smoothstep` 的结果，给 `step` 喂一个 `frac` 的结果，在 UV 上叠加 `sin(time)` 的抖动——每种组合都能产生完全不同的视觉。对着色器新手来说，最有价值的练习不是学更多语法，而是把这些基础函数的行为吃透。
