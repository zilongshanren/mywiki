# 双向路径追踪（Bidirectional Path Tracing，BDPT）

**双向路径追踪**是路径追踪（PT）和光线追踪（LT）的超集：它同时从相机和光源各自生成一条子路径，然后将两条路径的所有顶点组合连接，得到覆盖各种光路策略的完整估计。Eric Veach 在其博士论文中系统建立了这一框架，并与多重重要性采样（MIS）结合，给出目前无偏蒙特卡洛渲染的通用基准。

## 核心思路

设相机子路径有 $s$ 个顶点（$x_0 = $ 相机，$x_1, ..., x_s$），光源子路径有 $t$ 个顶点（$y_0 = $ 光源，$y_1, ..., y_t$），则路径长度为 $s+t-1$（中间连一段影子射线）。所有合法的 $(s, t)$ 组合对应该路径长度的不同采样策略：

- $(s, t) = (k, 1)$ → 传统路径追踪直接命中光源
- $(s, t) = (k, 2)$ → 路径追踪 + next event estimation（连接光源面一点）
- $(s, t) = (2, k)$ → 光线追踪连接相机
- $(s, t) = (1, 1)$ → 直接连接相机和光源（用于点光源）

朴素实现对同等长度的所有策略取均等权重（$1/n$）；正确做法是用 MIS balance heuristic 对每种策略按其各自 PDF 加权，大幅降低方差。

## 关键技术细节

**连接项 G 不可消除。** 当两端子路径通过影子射线连接时，连接顶点对之间的几何项 $G(x_s \leftrightarrow y_t)$ 无法被任一端的 PDF 约分，必须显式计算。遗漏这一项是 BDPT 实现中最常见的隐蔽 bug，表现为收敛到偏低亮度的"正常"图像。

**调试困难。** 相比 PT 的黑点 / 萤火虫等显眼错误，BDPT 中缺少一个符号或一个 cos 项会让图像看起来"几乎正确"，只在高频光路（如焦散）上偏暗。逐策略分通道可视化是定位问题的有效手段。

**场景依赖性明显。** 朴素 BDPT 在聚光灯 + 镫形场景（光源小、间接照明主导）表现优于 PT；含镜面物体时 LT 和 BDPT 收敛更快；漫反射主导场景下 PT + NEE 往往足够且更简单。

## 与 Instant Radiosity 的关系

[[instant-radiosity-vpl]] 是 BDPT 的特例：固定相机侧路径长度为 2（一段主光线），光源侧路径长度任意，且光路顶点（VPL）被所有像素样本共享而非每样本独立生成。这让它牺牲了无偏性换取更低的每样本成本，但在有镜面物体或复杂光路的场景中表现远逊于完整 BDPT。
