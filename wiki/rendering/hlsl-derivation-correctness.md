# 做完推导再写 Shader：常见偷懒清单

ryg 在这篇短檄文里列了一份「写完一段数学代码后花 5 分钟回看一眼」的检查单，核心立场是：**绝大多数「这段 math 很慢」的代码，不是因为缺 SIMD、缺 intrinsics，而是因为**作者没把推导做完，把一个还能化简两步的中间形式直接提交了**。

## 对称性

如果问题有明显的对称中心或对称轴，先把坐标系挪过去再解。「对称性求解通常给出干净又高效的答案」——就算没有收益，试一次也只花几分钟。

## 几何 > 代数

若问题本质是几何的，先画图，哪怕你已经会用代数解。几何解法中每个中间量都有意义（点、距离、比值），**debug 时能看着数值给 sanity check**；代数解法的中间步骤往往只是 solver 的黑箱临时量，出了错极难定位。

## 别用角度，尤其别用绝对角度

- 角度通常不是你真正要的；
- 角度会把 trig 函数塞进代码；
- 角度会引入参数化伪影（wraparound 的边界情况）；
- 用向量表达的同等代码更清晰、通常也更快；
- **绝对角度**（相对某个武断的全局坐标系的角度）尤其危险：某一天它会跨过 ±π 边界，然后奇怪的事情就开始发生。

## 反三角后立刻跟 sin/cos：停下来查恒等式

ryg 特别痛恨这一类代码（下面取自一个 Oren-Nayar shader 的早期简化版）：

```hlsl
float alpha = max(acos(dot(v, n)), acos(dot(l, n)));
float beta  = min(acos(dot(v, n)), acos(dot(l, n)));
C = sin(alpha) * tan(beta);
```

三个 acos、一个 sin、一个 tan、一个 min、一个 max，还需要配一张 LUT 纹理。动用一些最基本的恒等式——acos 在定义域内是单调**递减**的，所以 `max(acos(a), acos(b)) = acos(min(a, b))`；以及 `sin(acos(x)) = √(1−x²)`、`tan(acos(x)) = √(1−x²)/x`——上面整段等价于：

```hlsl
float vdotn = dot(v, n);
float ldotn = dot(l, n);
C = sqrt((1.0 - vdotn*vdotn) * (1.0 - ldotn*ldotn)) / max(vdotn, ldotn);
```

**没有 LUT 了，精度反而更高**，指令数大幅下降。ryg 的吐槽：「这都在 Wikipedia 的三角恒等式列表里，花两分钟查一下就行」。

> `atan2` 接 `sin`/`cos` 是「世界上最贵的 2D 向量归一化」。`acos(dot(a, b))` 接 `sin`/`cos` 紧随其后。

## 基本线性代数

- **符号矩阵乘法**：如果你把几个变换矩阵连乘当成性能热点，第一反应不应该是上 SIMD，而是用符号把矩阵乘开，生成结果公式直接套，而不是运行时再乘一遍。**在注释里写清楚你连乘的顺序**，给后人留条活路。
- **正交矩阵用转置代替逆**——前提是**orthonormal**（单位长度的正交基），数学家们在评论区里反复确认了术语：矩阵的「orthogonal」标准定义就已经蕴含 `Q^T Q = I`，即基向量既正交又单位长度，所以用转置就是逆。但如果你自己写代码，别指望「正交但没单位化」的基能这样，请老老实实归一化一次。
- **别到处用 4×4 矩阵**——除了投影矩阵，你的大多数变换都是仿射的，3×4 甚至 3×3 就够了。

## 不必要的数值微分

数值微分本质上是病态的，很难做得 robust，而且**大多数时候完全没必要**。如果你的函数是解析定义的，直接对它求解析导数：更准、更快，还省去了稳定性地雷。

> 警告：如果在送入前对参数做了 warp（比如 squared distance → distance 再给别的函数），**别忘了链式法则**。

## 迭代法 > 直接法（评论区补充）

评论区一位工程师补充：涉及数值算法时，**首选自校正的迭代法而非直接法**。即便像 Gaussian elimination 这样的经典直接方法，在病态问题上也需要迭代精化来保证稳健。像三次方程求解那种「漂亮闭式」最容易让人中招——条件数一差就飞，而且没有自动纠偏能力。

迭代法的最大价值是**中间误差几乎不重要**——你总能靠残差往回修。但停止条件是另一个巨大的坑（误差 vs 残差条件数、delta 的不确定性圆等），仍然需要认真设计。

## 基本情绪

> 「每发布一段半吊子数学代码，上帝就把一只毛绒绒的小猫喂给一只脾气糟糕的熊猫。」

短版本：**别只因为「第一版能跑」就把它提交**。再花 5 分钟回看一次，看看有没有漏掉的化简。
