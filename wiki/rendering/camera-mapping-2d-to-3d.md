# Camera Mapping（把 2D 画作投射成 3D 动画）

**Camera mapping** 是一种把一张 2D 插画直接「贴」到粗糙 3D 几何上的技巧：在建模软件里，用一台固定的参考摄像机把整幅图像作为贴图投影到场景中，每个多边形获得它在参考视角下覆盖的那块像素。只要观察摄像机不离参考视角太远，画面看上去就几乎完全保留 2D 绘画的笔触、透视畸变、轮廓线，暂停任意一帧都像静帧插画；但它又是真正的 3D，可以让角色眨眼、转头、摆臂，甚至让摄像机绕飞。Joost van Dongen 用这种方法把 Marlies Barends 的 *Evil Pope* 和 Roderick Leeuwenhart 的 webcomic *Captain August* 变成了带面部表情与呼吸感的短片，效果接近 *Anno 1404* 片头故事画的「会动的插画」。

传统 camera mapping 多用于室外环境矩阵打光，Joost 的贡献在于把它用到角色上，并证明即使是「破碎透视」（例如 Captain August 画面里顶部的圆顶根本不在一个灭点上）和「整组物体共用一根粗白描边」这类 3D 很难复现的特征，camera mapping 都能自然保留。

## 操作要点

- **用 3ds Max 的 *Camera map* 修改器**——工具层面一个 modifier 就能搞定投影，无需手写 shader。
- **不要用多边形还原物体边缘**。画作的边缘是有笔触、有模糊、锯齿起伏的，而多边形只能给出硬直线。正确做法是让边缘来自图像 alpha：多边形可以随意外扩甚至拉得很长，真正的轮廓由贴图透明度决定，这样建模反而更简单。
- **拆成很多图层**。想用透明度，就得在 Photoshop 里把原图切成许多独立 layer，并把被遮挡的部分在后面补画出来。*Evil Pope* 只拆了 3 层（头、身体、荆棘），*Captain August* 拆了 28 层。层越多，3D 场景越好搭。
- **给一切加一点曲面**。完全贴在平面上的角色一旦摄像机动就秒变「纸板人」；把躯干、手臂稍微弯成近似真实体型的曲面，并把四肢放到独立 layer 上，立体感立刻回来。但别弯过头——侧视时线条会被压缩失去 2D 味道。
- **映射完之后再做动画**。camera map 完成后，网格可以自由绑骨骼、表情可以通过 morph target 改变，眨眼之类的小动作也可以单独换贴图；这些都不会破坏「还是一幅画」的错觉。

## 风格定位

它本质上是一种「以画代建模」的美术工艺折中：避开 3D 建材质还原原画笔触这一几乎不可能的任务，直接借用原画像素；代价是摄像机角度被原画锁定、场景很难重打光。对独立开发者而言，这是一条以极小美术量换取高度独特视觉风格的捷径——Joost 在第三篇里明确表示有兴趣用它做实时 3D 小游戏原型。
