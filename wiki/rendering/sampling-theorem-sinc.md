# 采样定理与 sinc 函数

Shannon-Nyquist 采样定理告诉我们：带宽有限的连续信号 `f(t)` 可以由它在等距整数点的采样精确重建——重建公式是用 **sinc 函数** 作为插值核。问题在于：傅里叶理论里出现的几乎全是三角多项式（正弦余弦的有限和），那么 `sinc(x) = sin(πx) / (πx)` 这个分母里突然冒出来的 `x` 是从哪里来的？

## ryg 的回答：sinc 是 Lagrange 多项式的极限

Euler 有一个漂亮的恒等式

```
sin(πx) / π = x · ∏_{k=1}^{∞} (1 - x²/k²)
```

把右边稍微整理一下，可以写成所有整数节点 `k` 的因式连乘形式。再对照 **Lagrange 基本多项式**

```
L_j(x) = ∏_{k ≠ j} (x - x_k) / (x_j - x_k)
```

在 `x_k = k`（所有整数）时的形式，会发现 `sinc(x - j)` 正是 Lagrange 在「无穷多等距控制点」下的极限——每一个整数采样点对应一个 `sinc` 平移。换句话说：

> **sinc 插值 = 用所有整数节点做的多项式插值在节点数→∞ 下的极限。**

## 与渲染的联系

- 在 [[aliasing|纹理重建 / 抗锯齿]]里，sinc 是理想的低通滤波器，但因为它是无限支撑的非负且非紧支的核，工程上只能用截断 sinc（Lanczos）或 cubic / Mitchell 等近似来代替。
- 这些近似都可以理解成「用某个有限 Lagrange / B-样条核去近似无穷多节点的极限」。
- 反过来，傅里叶视角的解释也成立：带限函数的频谱可以用 `rect` 函数周期延拓再反 FT，恰好得到 sinc 平移族。两种推导导向同一个公式。

## 哲学

这是一个反复出现的图形数学母题：**一个看起来很神秘的公式，往往是一个熟悉对象在某种极限下的样子**。Lagrange 插值是离散的、组合性的；sinc 是连续的、解析性的——但它们其实是同一族对象的两端。理解这一点会让 Lanczos 滤波、bicubic 插值、傅里叶域去走样这些技巧都变得「同源」。
