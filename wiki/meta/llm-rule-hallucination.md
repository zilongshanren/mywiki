# LLM 规则幻觉与鉴别困境

LLM 在冷门 / 新发布 / 长尾知识上的一个典型失败模式：**对规则细节胡编乱造，却表达得比真懂的人还自信**。[[cloudwu|云风]] 在学习 2025 年刚发布的桌游 Star Trek: Captain's Chair 规则时集中观察到这个问题——Gemini 在网上资料稀缺的情况下，不但虚构出根本不存在的"规则条目"，还会杜撰规则书章节号、杜撰 BGG 论坛帖子的引用内容，反复追问都保持"信誓旦旦"。更隐蔽的一例：Gemini 确实搜了 BGG 论坛，但**把论坛里玩家反复强调的关键差异（A/B 面导轨设计不同）忽略掉**，反而拼凑出一堆错误解释。

这个现象与"[[ai-assisted-reading-workflow|AI 辅助阅读]]"里正面例子（Gemini 加上下文把 We/Our 翻译成"朕"，与中译版一致）形成了鲜明对比。同一个工具：

- **已有基础 + 验证成本低**的场景（翻译、读概念性文字）→ LLM 加速理解，偶尔错了读者自己能发现
- **完全外行 + 验证成本高**的场景（学陌生规则、入门新领域）→ LLM 的错误和正确答案**在语言表达上完全无法区分**，还会浪费更多时间去伪造的章节号和论坛帖子里找

一个对比锚点：人类玩家如果自己没玩过这个桌游，被问规则细节时**不会**表现得如此自信，会先说"不太清楚"。LLM 则把"语言表达能力"和"实际知识的边界意识"完全解耦——表达力是训练目标，对知识边界的自认很少被校准。

云风给的实用结论："如何辨别 LLM 提供的信息中哪些确有价值会变得更加重要。LLM 的语言表达能力越来越强，也会变得越来越有欺骗性。"

这也是 [[cloudwu]] 这条技术线对 AI 辅助工作流的一贯立场：不否定工具本身，但**对"解释型答案"保持警惕，坚持回到原始材料**（规则书、论坛 FAQ、一手代码）验证关键细节。
